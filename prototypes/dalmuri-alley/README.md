# 달무리 골목 (프로토타입)

가상 사주·타로집 아이디어의 껍데기. 엔진과 무관한 임시 실험이며, 실제 앱은 별도 저장소에서 만든다.

- `index.html` 한 파일, 빌드와 의존성 없음. Claude Artifact 게시용 조각이라 `<html>`/`<body>` 태그가 없다.
- 대사는 고정 대본(`reading()`, `session()`), 음성은 브라우저 내장 TTS(`Voice.speak()`).
  실제 앱에서는 각각 LLM 호출과 ElevenLabs 스트리밍으로 교체하는 자리다.
- 사주 부스는 만세력 엔진이 없어서 닫아 두었다.
