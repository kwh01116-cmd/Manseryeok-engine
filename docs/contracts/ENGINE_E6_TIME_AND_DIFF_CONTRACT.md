# E6 시간 컨텍스트와 변화분

## 시각과 발급 계보

`AS_OF`는 `asOf`, `COMPARE`와 `RANGE`는 `from`과 `to`를 `YYYY-MM-DDTHH:mm` 형식으로 명시한다. KST 발표 분의 의미와 M7 명목 교운 구간을 유지한다. 확장 조회 정책도 2028년 절기 및 2027년 음력 자료의 결손을 보충하지 않는다.

`natalCandidateRef`는 같은 응답의 원국 후보에 묶인다. 각 조회 분의 `timeContextRef`는 운의 양립 가능한 조합과 연결된다. 연운·월운이 같은 입춘 사건을 쓰면 전/전과 후/후만 발급한다. 날짜가 같은 원국이라도 출생 후보의 증거를 다른 부모의 운 근거로 참조할 수 없다. 토왕 등의 계절 대안은 기존 원국 아래에 그대로 둔다.

활성 운은 `layers.DAEUN`, `layers.SEYUN`, `layers.MONTHLY`에서 구간과 시작·종료 근거를, `positions`에서 적용 위치를 조회한다. 출생 전, 첫 대운 전, 생성한 열 밖, 대운 입력 부족, 자료 부족을 구별한다. 조회 분에 확인된 간지에 종료 자료가 빠지면 위치와 미확정 기간을 함께 기록한다. 관계 집계의 `unavailableLayers`는 확인 범위가 닫히지 않은 운을 알려 준다.

`RANGE`의 범위는 최대 366일의 반개구간이다. 기존 운 경계와 발표 분의 양립 가능한 대안으로 나눈다. 하나의 모호한 발표 분은 후속 분과 구분해 표시한다. 구간 64개, 원국당 시간 컨텍스트 128개, 응답 관계·변화 행 8,192개가 상한이다. 초과는 `LIMIT_EXCEEDED`다.

## 위치·동일성·변화

기존 원국의 위치와 새 운 기간 위치를 보존한다. 같은 간지라도 새 운 기간의 위치에는 서로 다른 `periodRef`가 생긴다. 관계 `key`는 원국/운의 위치·기간 인스턴스에 묶이고 관계 `shapeKey`는 기호와 관계 형태를 식별한다. 조회 분이나 배열 순서가 달라져도 동일 기간에 연결된 관계는 유지된다.

비교는 각 원국 부모 아래에서 양립하는 시간 컨텍스트끼리 진행한다. `added`, `ended`, `maintained`는 쌍의 관측 변화다. 상대 시점에 필요한 운의 확인 범위가 닫히지 않으면 `uncomparable`로 기록한다. `triadChanges`는 세 가지 서로 다른 지지의 배치와 기간 인스턴스를 함께 비교한다. `changedLayers`에서 어느 운이 바뀌었는지 읽는다. 여러 대안에서 공통인 관계 키와 일부에서만 가능한 키는 요약에서도 분리한다. 실제 사건과 효력의 해석은 이 계약 범위 밖이다.

## E5 상태의 읽기

통관에 대해 서로 다른 대상 관계의 병존, 같은 대상 위치의 대안 경로, 경로별 간섭을 함께 표시한다. 실제 필요성과 효력은 각각 `NOT_EVALUATED`다. 원래의 `COMPETING_PATHS`와 버전은 E5에 보존한다.

조후는 `coverage`(실행·제한 관측·규칙 없음), `status`(후보·대상 관측·경합·보류), 실제 후보 유무와 대상·대안 천간 위치를 따로 반환한다. 관측한 요소의 충분성은 미평가 상태다. [관계 정책과 제한](../research/ENGINE_E6_NATAL_TRANSIT_RELATION_POLICY_V01.md)
