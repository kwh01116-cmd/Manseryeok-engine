## 결론과 상태의 의미

**기존의 “KASI 자료는 권리가 전혀 확인되지 않았다”는 일괄 표현은 더 이상 정확하지 않다.** 두 API의 현재 공식 목록에서 이용허락 제한 없음이 확인됐고, 현재 계산 행을 그 API 응답과 연결할 수 있다. 이 범위의 상업 앱 계산·저장·가공·서버 내부 사용은 `VERIFIED_ALLOWED_WITH_CONDITIONS`로 분리할 근거가 있다. 반면 현행 7파일 attachment 전체의 고객 배포, 다른 발행물·OSS 내장표까지 일괄 승인하지 않는다.

| 코드 | 이 감사에서의 의미 |
| --- | --- |
| `VERIFIED_ALLOWED` | 명시한 행위와 자료 범위의 허용 표시를 직접 확인함. 다른 자료·다른 행위로 확대하지 않음 |
| `VERIFIED_ALLOWED_WITH_CONDITIONS` | 허용 근거를 확인했으며 제3자 권리·정확한 계보·고지 등 명시한 조건을 함께 적용함 |

| `VERIFIED_RESTRICTED` | 해당 저작물의 명시된 제한을 확인함. 제한의 대상/행위를 특정함 |

출처 표시는 재현성과 오인 방지를 위해 **프로젝트의 필수 고지**로 채택한다. R1/R2가 별도의 출처표시 조항이나 특정 공공누리 유형을 부착했다는 의미는 아니다. 표시 예: “날짜·절기 자료: 한국천문연구원 공공데이터포털 특일 정보(15012690)·음양력 정보(15012679), 자료조회/정규화 버전과 사용 정책은 기술 정보 참조.” 변형 항목에는 우리 프로젝트의 시계 해석·계산 결과임을 구별한다. API키·ServiceKey·인증 URL은 출처 고지에 넣지 않는다.

## 출시 차단의 갱신과 최소 확인 질문

갱신할 범위는 **API-only 내부 상업 계산의 권리 근거가 확인됐다는 점**이다. 미확인인 역사시 정확성·2027 이후 시계 정책·전체 공개 패키지·출시 운영 게이트를 이 결론으로 해제하지 않는다. 포털 목록 표면만 읽고 `RIGHTS_BLOCKED` 전부를 지우는 것도, 확인한 영리 이용 근거를 무시해 모든 KASI 사용이 계속 미확인이라고 쓰는 것도 피한다.

외부 확인이 필요한 최소 질문은 다음과 같다. **아직 발송하지 않았고, 기관 연락이 필요해지면 사용자의 별도 승인을 받은 뒤 전달한다.**

1. 두 API의 현재 이용허락 제한 없음이 이미 수집한1950–2027 응답을 정규화한 날짜/절기 파일의 상업 앱 동봉 배포에도 적용되는가? 별도 고지/공공누리 유형/재배포 조건이 있는가?
2. API 응답의 factual 값을 이용하는 것과 같은 연도 월력요항 공고 저작물(R5,KOGL2)·발표 보도자료(R6,KOGL1)를 복제/변형하는 것을 기관은 어떻게 구분하는가? 동일 첨부에 다른 표시가 있을 때의 적용 대상은 무엇인가?
3. KASI 연간 TXT·역서·예비 달력표에서 추출한 데이터는 API와 별도 허락인가? 제3자 내장표까지 포괄하는 권한을 주장하지 않고 기관 소관 자료만 확인한다.

확인이 필요한 배포 범위의 질의를 준비한 것이지, 모든 내부 개발을 중단하거나 새 API 수집을 요구하는 결론이 아니다. 기존 API-only 자료의 기술 검증과 새 선택형 프로필 구현은 계속 진행할 수 있다.
