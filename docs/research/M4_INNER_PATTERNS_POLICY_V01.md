# M4 내격8 월령 구조 정책 v0.1

정책 ID `M4-INNER-EIGHT-MONTH-STRUCTURE-V01`, 버전 `0.1.0`. 기존 정관격 `M4-ZHENGGUAN-MONTH-STRUCTURE-V01`을 수정하거나 대체하지 않는 별도 선택 정책이다. 대상은 正官·七殺·正財·偏財·正印·偏印·食神·傷官의 **월령 구조 후보**다. 成格·破格·救應·격국 우열·실제 강약·도움이 되는 용신을 확정하지 않는다.

## 근거와 프로젝트 선택

기존 [정관격 정책](M4_ZHENGGUAN_STRUCTURE_POLICY_V01.md)의 《子平真詮》「論用神」「論用神變化」 월령·장간 투출 문맥과 기존 M2/구조적 M3를 재사용한다. 해당 원전 전사 확인 수준은 기존 source registry의 확인일·표면·판본 미확인 상태를 그대로 따른다. 이번에 여덟 격의 원전 효력 이론을 새로 전수 인증한 것은 아니다.

다음 결정표와 유형별 방향 정리는 **PROJECT_POLICY**다. 본기·정확 투출·경쟁을 재현 가능하게 구분하기 위한 선택이며, 모든 학파의 단일 취격 알고리즘이라고 표시하지 않는다. 특히 辰戌丑未의 본기 속성으로 사령일수·實際旺衰·雜氣格의 성패를 확정하지 않는다. 기존 MAIN_QI/OTHER를 中氣/餘氣의 새 순서나 배점으로 바꾸지 않는다.

KASI는 역법·적용 절입의 출처다. 격국 규칙의 저자로 사용하지 않는다. 월령에서 취한 격국 기준은 M5의 균형·조후·희용신과 다른 타입이다.

표면 네 위치의 정확 일치는 모두 기록하되, 후보 취출에는 연·월·시의 비일간 노출만 사용한다. 일간 자신과의 일치를 비견격 경쟁으로 만들지 않는다. 같은 글자가 여러 위치에 반복되면 각 위치를 보존한다.

## 유형별 관측과 효력의 구분

각 방향은 기존 `fiveElementRelation(from.element,to.element)` 및 이미 계산한 십성/위치로 확인한다. helper enum의 DAY_MASTER라는 단어는 두 피연산자의 관계 명칭이며 실제 원국 일간을 바꾸는 연산이 아니다. 숨은 위치와 표면 위치를 합치지 않고, 근의 강도·합충 작용·유리/불리를 수치화하지 않는다.

| 후보 유형 | 이 버전에서 수집하는 실제 위치·방향 | 확정하지 않는 효과 |
| --- | --- | --- |
| 정관 | 재→정관, 정관→인, 상관→정관 극 방향, 정관·칠살 병존 | 財生官의 충분성·傷官見官 파격·관살 정리 |
| 칠살 | 식상→칠살 극 방향, 칠살→인, 재→칠살 | 制殺·化殺의 실제 성공·살의 경중 |
| 정재·편재 | 식상→재, 비겁→재 극 방향, 재→인 극 방향 | 재의 힘·비겁 탈재·재극인 효력·재물 결과 |
| 정인·편인 | 관살→인, 인→일간, 재→인 극 방향; 편인은 편인→식신 극 방향도 별도 관측 | 실제 생조 전달·財破印·梟印奪食 |
| 식신 | 비겁→식신, 식신→재, 인→식신 극 방향, 식신→칠살 극 방향 | 食神生財·制殺·奪食 성패 |
| 상관 | 비겁→상관, 상관→재, 인→상관 극 방향, 상관→관살 극 방향 | 傷官佩印·見官·制殺의 효력 |

正/偏의 정확 십성 타입과 위치는 분리하되 동일 오행의 방향 정의를 공유할 수 있다. 상관→관살은 CONTROL_REVIEW의 중립 관측이다. 상관제살까지 일반적인 방해 효과로 묶지 않는다. SUPPORT/ADVERSE/CONTROL은 검토 항목의 분류이며 실제 작용 판정이 아니다. 관측이 없으면 NOT_OBSERVED이고, 효과가 미정인 것을 효과0으로 바꾸지 않는다.

## 결과·참조와 다음 M5 입력

`deriveM4InnerPatterns(evidence,{profileId,m2Facts})`는 같은 실행에서 발급된 기존 M3와 원래 M2를 검증해 사용한다. M1이나 십성·장간표를 다시 구현하지 않는다. 후보별 여덟 pattern의 assessment, 월령 장간·노출·위치, presence, 유형별 observations, competition, selection, required policies와 source/rule/evidence/fact/member 참조를 제공한다. 설명도 같은 assessment/observation을 참조하며 변조를 거절한다.

M5가 소비할 월령 기준·후보/경쟁·정확 노출·日干·실제 위치·생극 방향과 미평가 효과는 확보된다. 그러나 어떤 목적의 M5 정책을 사용할지, 원국의 실제 힘과 전달을 어떻게 평가할지는 별도 선택이다. 해당 입력을 확보했다는 이유로 도움이 되는 용신·희신·기신을 발급하지 않는다.

입춘의 두 원국은 각각 분석하고, 토왕 B의 한 원국 아래 두 계절 대안은 새 M4 원국/격국 집합으로 복제하지 않는다. 성별값·대운·세운·조회시각·실험 점수는 같은 원국의 M4 구조 선정을 바꾸지 않는다. 기존 M3의 좁은 결론과 `finalStrength=NOT_IMPLEMENTED`, G0/G1-P2·최종 해석/출시 게이트는 그대로다.
