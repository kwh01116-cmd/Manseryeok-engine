# M3 evidence v0.1 — 명식 구조 근거만 정리하는 선택형 정책

정책 **`m3-structural-evidence-local-v1`**, 구현/조합 버전 **0.1.0**, 결과 상태 **`EVIDENCE_ONLY`**다. 기존 M1이 계산한 후보와 기존 M2가 분류한 위치·장간·십성·지지 관계를 근거 목록과 한국어 템플릿으로 연결한다. 새로운 신강약 공식이나 전통 학파의 판단을 만들지 않는다.

기존 [M3 최종 신강약/격국/용신 gate](M3_STRENGTH_GO_NOGO_DECISION_SPEC_20261018.md)는 변경하지 않았다. 이번 사용자 승인은 이 문서의 구조적 근거 조합에 한정되며, 최종 신강약은 **`NOT_IMPLEMENTED`**, 해석 release gate는 **`M3_FINAL_BLOCKED_UNCHANGED`**로 남는다. 기존 M2의 `READY`가 M3 신강약 준비 완료로 바뀌지 않는다.

## 새 전통 규칙과 구조적 정의의 구분

| 자료/연산 | 실제 사용하는 근거 | 이번에 하는 일 | 하지 않는 판정 |
| --- | --- | --- | --- |
| 월 문맥 | 같은 M2 후보의 SUMMARY·월주 nature·월지 hidden-stem facts | 일간·월주·월지 대표 오행·선택한 실제 절입/표시 분·경계 전후를 보존 | 득령·왕상휴수사·사령·계절 세력 |
| 통근 검토 후보 | 기존 장간 구성원과 `STEM_NATURE` | 일간과 천간 **문자가 같은** 위치와 **오행만 같고 문자는 다른** 위치를 구분 | 유효한 통근 성립·뿌리 강도·장간 세력 |
| 다섯 방향 | 기존 `tenGods.ts`의 같은 오행/생/극 관계 함수 | 일간 기준 위치를 다섯 방향으로 나열 | 도움/손해의 크기·지원 총량·오행 비율·신강약 |
| 장간↔표면 연결 | 같은 후보의 실제 장간·네 표면 천간 | 정확히 같은 천간 문자끼리 모든 위치 연결 | 전통적 투간의 작용·활성·강도 |
| 관계 문맥 | 기존 M2 쌍 관계/삼합·삼회 facts | 방향·중복 위치·겹침·완전/부분·빠진 구성원을 모두 보존 | 합화·상쇄·우선순위·실제 효력·길흉 |

새 출처 ID `IMPL-M3-STRUCTURAL-EVIDENCE-V1`은 위 구조적 정의/조합 코드만 가리킨다. 기존 M2의 정책·규칙·출처 ID와 native version을 그대로 연결하며 전통 원전의 새 판정이라고 표시하지 않는다. 별도의 계절 세력·효력 원전 근거를 닫지 않았으므로 그 항목은 계속 `UNRESOLVED`다. 구조적 정의를 구현하는 데 새 외부 전통 표나 점수표를 추가하지 않았다.

## 구체적인 위치 계약

입력은 기존 로컬 M2 envelope의 한 번 계산된 결과다. 후보 ID는 `chart.candidates[i]`이고, 네 기둥의 순서는 연·월·일·시다. 각 위치에는 다음이 남는다.

- 표면/장간 구분, 후보·기둥·장간 index, 천간·오행·음양, 기존 십성.
- 원래 M2 fact ID, 장간 member ID와 M2 위치 경로.
- 원래 rule/policy/source refs와 별도의 계산 자료 refs.
- 본기 `MAIN_QI` / 기타 장간 `OTHER` 표시. 이는 기존 표의 표시/구성원 순서이며 가중치가 아니다.

같은 글자가 연주와 월주에 나오면 서로 다른 위치다. 한 입력에서 동일 fact ID·장간 ID·장간 위치가 중복되면 거절하며, 서로 다른 기둥의 정상 반복은 제거하지 않는다. 지지 하나를 단일 십성으로 축약하지 않고 기존 장간별 결과를 유지한다.

`rootCandidates.exactStem`에는 장간 중 일간과 천간 문자가 같은 위치만 둔다. `sameElementDifferentStem`에는 오행은 같지만 천간 문자는 다른 장간만 둔다. 두 집합을 섞거나, 목록이 비었다는 이유로 통근/신강약 결론을 내리지 않는다.

`directionalGroups`는 다음 다섯 관계다. 기존 private 관계 함수의 이름/타입만 export하여 재사용했으며 생·극 표와 함수 본문, 기존 십성 계산 결과는 바꾸지 않았다.

| ID | 구조적 의미 |
| --- | --- |
| SAME | 일간과 같은 오행 |
| TARGET_GENERATES_DAY_MASTER | 대상이 일간을 생하는 방향 |
| DAY_MASTER_GENERATES | 일간이 대상을 생하는 방향 |
| DAY_MASTER_CONTROLS | 일간이 대상을 극하는 방향 |
| TARGET_CONTROLS_DAY_MASTER | 대상이 일간을 극하는 방향 |

이 묶음에는 연·월·시의 표면 천간과 **네 기둥의 모든 장간**이 들어간다. 일간 자신인 **일주 표면 천간**은 추가 지원으로 넣지 않는다. 일지의 장간은 일간 자신과 별도 위치이므로 포함된다. 개수·가중합·세력 비율을 계산하지 않는다.

반면 `hiddenVisibleLinks`는 네 표면 위치를 모두 대상으로 하므로 일주 표면 일간도 포함한다. 장간 글자와 표면 글자가 정확히 같을 때만 연결한다. 오행만 같은 다른 천간은 연결하지 않는다. 이 연결과 일간 자기 자신 제외 규칙은 서로 다른 목적의 구조적 정의다.

## 월령·절입과 관계의 미해결 경계

`monthContext`는 해당 후보의 실제 월주와 M2 SUMMARY에 담긴 적용 절입, 표시 분, `KST`/`MINUTE`, source refs, BEFORE/AFTER/DEFINITE 조건을 보존한다. 월지 대표 오행은 기존 `BRANCH_NATURE.principalElement`의 표면 분류다. 본기 장간과 그 일간 기준 십성도 별도로 남기며 이를 계절 사령이나 힘으로 바꾸지 않는다.

시즌 문맥의 상태는 **`UNRESOLVED`**다. 입춘 등에서 두 후보가 있으면 월주·절입·장간·방향·관계와 설명이 각 후보 안에서 달라질 수 있으며, 첫 후보 선택·서로 다른 후보 조합·확률 부여를 하지 않는다.

`relationContext.pairs`/`triads`는 기존 M2 분류를 그대로 보존한다. 예를 들어 巳申의 육합·형·파가 겹치면 하나를 지우지 않는다. 동일 지지의 여러 기둥 위치도 그대로 남는다. 삼합·삼회는 서로 다른 구성원 수와 각 구성원의 모든 기둥 위치, 빠진 구성원 및 기존 부분 분류를 보존한다. 관계/구성원 존재와 실제 효력은 별개여서 `effectStatus=UNRESOLVED`다. 十二運星 facts는 기존 M2에 그대로 두고 근력/신강약의 점수로 소비하지 않는다.

## 실행·참조·출처 검증

순수 함수는 `src/m3/structuralEvidenceV1.ts`의 `deriveM3Evidence(m2,{policyId})`, `explainM3Evidence(evidence)`, `validateM3Evidence`, `validateM3EvidenceExplanation`다. 새 CLI/어댑터는 이 조합 함수와 분리한다. 네트워크·LLM·파일 저장·M1 또는 M2 전체 재계산은 순수 모듈에 없다.

순수 입력 검사는 후보·기둥·fact/member 위치의 일관성, 기존 nature/십성 helper에 따른 값, 명시 M2 정책, 존재하는 rule/policy/source·계산 refs를 검사한다. 실제 API 응답이나 외부 원본의 진위를 인증하지 않는다. `inputAuthentication=NOT_PERFORMED_BY_PURE_MODULE`이고, 로컬 어댑터가 기존 same-process M1/M2 발급 객체와 입력/출처 연결을 별도로 확인해야 한다. 합성 테스트는 `STRUCTURAL_TEST_CALENDAR_REFERENCE`처럼 명시적인 비출생 자료를 쓸 수 있으며 가짜 KASI 응답 지문·G0 receipt가 필요하지 않다.

출력 전체를 불변으로 만들고 작은 발급 집합으로 해당 evidence 객체를 확인한다. 다른 요청이나 JSON 복제로 신뢰를 재개하지 않는다. 설명은 발급된 근거만 소비하는 버전형 한국어 템플릿이며 다음 경로를 따른다.

```text
설명 evidenceRefs
→ 같은 후보의 evidence ID
→ inputFactRefs / inputMemberRefs / 기둥 위치
→ 기존 M2 fact/member
→ 원래 rule/policy/source + 계산 자료 refs
```

누락·교차 후보·없는 규칙/출처·중복 위치·변조된 설명은 조용히 무시하지 않는다. 입력 M2의 **7개 null runtimeVersion은 그대로 null**이며 조합 버전0.1.0을 기존 규칙의 원래 버전처럼 덮어쓰지 않는다. 원전 판본·권리·예측 효력 미확인은 이번 근거 정리로 승인되지 않는다. `g0Receipt=null`, `g1P2Promotion=false`를 유지한다.

## 설명과 검증 수준

한국어 설명은 일간·월주/절입, 정확 문자/같은 오행의 위치, 다섯 방향, 실제 장간↔표면 연결, 실제 발견한 지지 쌍과 삼합·삼회 구성원을 말한다. 반복되는 범위 제한은 공통 문구에 한 번 두고, 특정 부분 구성원·방향·미확정 사항은 해당 항목 가까이에 둔다. 입력에 없는 관계·효과·계절 이름을 만들어내지 않는다.

검사는 기존 M2 분류를 입력으로 연결했는지, 독립 유한 기대값과 위치/참조가 맞는지 확인하는 소프트웨어 검사다. 원전·학파의 신강약 정답이나 현실 예측 타당성을 인증하는 검사가 아니다. 실제 데이터/전체 회귀/브라우저/최종 실행 SHA는 별도 실행 기록으로 구분해야 하며 개발 중 집중 검사나 자료 수집 성공을 이 결과로 대신하지 않는다.

최종 신강약·점수·비율·격국·용신·조후·합화·관계 효력·길흉·개인 사건 예측, 새 UI/공개 배포, 역사시·지원 출생 범위 확대는 이 정책에 없다.
