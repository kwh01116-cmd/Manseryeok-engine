# M2 기존 유한 정책의 출처·회귀 연결 감사

**2026-11-07, 보고 전용.** 기존 코드와 저장소 연구 문서 사이의 누락을 탐지한다. 새로운 원전 연구나 학파 선택을 수행한 결과가 아니다. 외부 사이트를 다시 조회하지 않았으며, 이 감사가 원전·판본·권리·예측 효력을 인증하지 않는다.

## 실행과 범위

Node 22와 잠금 의존성이 설치된 저장소에서 `npm run m2:audit`를 실행한다. 빌드한 현재 정책 메타데이터를 [기계 판독 목록](m2-policy-catalog.json), 지정된 연구 문서·테스트 제목과 대조해 JSON 보고서를 출력한다. 외부 요청, 키 사용, 입력 자료 수집, 파일 갱신은 없다. 빌드 산출물만 기존 빌드 경로에 생성된다.

| 기존 정책 | 규칙 수 | 근거 기록 | 의미의 경계 |
| --- | ---: | --- | --- |
| 지장간 | 1 | [회원 목록과 본기 순서](M2_HIDDEN_STEM_SOURCE_GATE.md) | 고전의 구성원과 현대 본기 순서를 구분; 수치 세력·司令 아님 |
| 십이운성 | 1 | [양순음역·화토 정책](M2_TWELVE_GROWTH_POLICY_V1.md) | 선택한 학파의 단계 이름; 강약·길흉 아님 |
| 지지 쌍 관계 | 5 | [육합·충·해·파·형](M2_RAW_BRANCH_RELATIONS_SOURCE_GATE.md) | 원시 쌍 구성원; 관계의 성립·상쇄·효력 아님 |
| 삼합·삼회 구성원 | 2 | [완전·부분 구성원](M2_TRIAD_MEMBERSHIP_SOURCE_GATE.md) | 고유 구성원의 존재; 合化·국 성립 아님 |

9개 규칙, 12개 source ID(고전 계열 6, 현대 계열 6)가 대상이다. 이는 **M2 전체 규칙 등록부의 완성 선언이 아니다**. 지지 십신·ChartFacts 등의 조합 규칙과 상위 M0 메타데이터는 `compositionAndUpstreamRuleRecords: OUTSIDE_THIS_AUDIT`로 명시한다. 고전 4지 토국은 기존 정책에서 제외되어 있으며 이 작업이 추가하지 않는다.

## 탐지하는 불일치

- 정책·규칙·출처의 누락/중복/불필요한 추가, runtime policy ID·meaning·evidence layer·source IDs·codeability·dispute status·version과 목록의 불일치.
- 고전 구성원 출처와 현대 순서·단계·분류 출처의 혼동. 지장간 규칙 자체의 기존 `CLASSICAL_BASE_TEXT` 값을 바꾸지 않고, 두 출처의 기여를 각각 `CLASSICAL_MEMBER_LIST`와 `MODERN_MAIN_QI_ORDER`로 기록한다.
- 부분 삼합 결과에만 덧붙는 현대 source ID의 누락. 실제 부분 구성원 출력을 관찰하므로 완전 구성원용 `TRIAD_RULES`만 열거해 빠뜨리지 않는다.
- 해당 연구 문서에서 source ID가 사라지거나, 정책별 양성·반례 테스트 제목 연결이 없어지는 경우. 지정된 로컬 파일만 읽으며 목록에 적힌 임의 경로는 열지 않는다.
- 근거 검토 없이 `criticalEdition`, 판본 인증·이용권·해석 승격 필드를 채우는 경우. 새 증거를 받아 승격하려면 별도의 검토와 감사 계약 갱신이 필요하다.

테스트 제목의 존재는 **연결 확인**이다. 그 테스트가 실행되거나 통과했다는 뜻이 아니므로 `testsExecutedByAudit: false`를 출력한다. 실제 실행은 별도로 `npm run check`에서 확인한다.

## 현재 열린 항목

정상 종료 0의 상태는 `CATALOG_CONSISTENT_EVIDENCE_OPEN`이다. 내부 연결이 일치하면서 아래 항목이 열려 있음을 뜻한다. 목록·연결이 어긋나면 종료 1이다.

- source ID 12개의 비평 판본·판본 인증·재사용 권리는 이 목록에서 모두 미확인이다. URL·출처 이름만으로 인증하거나 재사용 권리를 부여하지 않는다.
- 지지 쌍 5개와 삼합·삼회 2개, 총 7개 규칙 객체에 독립 `version` 필드가 없다. 해당 `runtimeVersion`은 `null`, 보고서에는 규칙 ID를 열거한다. 정책 ID의 `V1`과 개별 규칙의 버전 필드를 구분하며 버전을 임의로 채우지 않는다.
- M2 전반의 비평 판본, 대안 학파, 조합·상위 규칙 등록부, 외부 독립 검토는 남아 있다. 이 감사가 M1 지원 범위, G1 원본 행 인증, P2 NO-GO, 제품·배포 게이트를 변경하지 않는다.
