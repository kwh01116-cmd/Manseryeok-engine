# E5 통관 구조 후보 정책 0.1.0

`E5-NATAL-TONGGUAN-V01`은 원국의 상극 방향과 두 단계 상생을 따로 조회하는 선택 정책이다. 대상은 네 기둥을 발급한 원국 후보다. 두 후보가 발급된 절입 경계는 각각 계산한다.

## 출전과 독립 관계표

《滴天髓》 「通隔論」 전사의 본문은 관계가 가로막힌 경우를 논한다. 붙은 주석에서 오행 다섯 쌍의 매개를 열거한다. 《滴天髓闡微》 「通關」 전사는 본문·원주·任鐵樵 주를 구분한다. 任注는 투출과 장간의 대응, 떨어진 자리와 방해 요소, 합·충으로 관계가 달라지는 조건을 검토한다. 두 전사에서 함께 확인되는 방향과 기존 오행 생극 함수의 교집합을 사용했다. 원국에서의 위치 선정이나 효력 판정은 이 목록만으로 결정되지 않는다.

- [《滴天髓》 「通隔論」 전사](https://zh.wikisource.org/zh/滴天髓/20)
- [《滴天髓闡微》 「通關」 전사](https://wuguo.org/novel/155/chapter/7785)

| 관측 상극 | 검토할 두 생 관계 |
|---|---|
| 목 → 토 | 목 → **화** → 토 |
| 화 → 금 | 화 → **토** → 금 |
| 토 → 수 | 토 → **금** → 수 |
| 금 → 목 | 금 → **수** → 목 |
| 수 → 화 | 수 → **목** → 화 |

## 프로젝트 운영 정의

1. **위치 관측.** M3가 발급한 일간·나머지 표면 천간·장간의 본기와 기타 장간을 사용한다. 일간을 후보 오행의 암묵적인 강도 근거로 사용하지 않는다. 각 위치는 한 번만 기록하며 지지 대표 오행을 본기와 이중 계상하지 않는다. 상극 양끝은 기타 장간에만 있어도 그 관계의 구성은 기록한다.
2. **구조 후보.** 양끝과 매개 모두가 표면 천간 또는 장간 본기인 실제 위치에서 두 생의 각 구간이 같은 기둥 또는 이웃 기둥을 연결할 때 경로를 반환한다. 한 원국 내 같은 오행이 여러 자리에 있어도 경로는 역할별 위치 세 개로 식별한다. 이웃 기둥 조건은 보수적인 v1 선정 범위다. 이 범위를 벗어난 매개 위치도 장간 위치와 함께 보류 사유를 반환한다.
3. **뿌리와 방해.** 표면 매개 자리에 대해서만 장간의 정확근과 같은 오행의 다른 천간을 나눠 기록한다. 이 관측을 근력 임계값으로 삼지 않는다. 경로의 표면 천간과 관련된 간합, 장간 위치 및 매개 천간의 정확근에 관련된 지지 합충형파해, 매개를 가까운 자리에서 극하는 표면·본기 요소를 보존한다. 경로의 출발 또는 대상 자리에서 해당 방향이 확인되면 같은 관측을 사용할 수 있다. 직접 관련된 증거만 경로의 경쟁으로 기록한다.
4. **상태.** 구조 후보를 낼 수 없으면 `HOLD`와 원인을, 관측된 상극 쌍이 하나도 없으면 `NOT_APPLICABLE`을 반환한다. 후보 오행이 하나이고 별도 간섭이 관측되지 않은 경로가 적어도 하나 남으면 `STRUCTURAL_CANDIDATES`다. 둘 이상의 매개 오행이 후보거나 해당 후보의 경로마다 관련 간섭이 관측되면 `COMPETING_PATHS`다. 다른 경로의 간섭을 전체에 일괄 적용하지 않으며, 각각의 경로와 위치는 보존한다.
5. **적용 한계.** 효력 상태는 `NOT_EVALUATED`다. 합화·합거·충으로 인한 근 손상·두 오행의 실제 세력·운에 따른 매개 추가는 평가 범위 밖이다. 매개가 없다는 보고는 추가해야 할 오행의 처방으로 이어지지 않는다. 억부와 조후의 결과는 독립 정책이다.

## 사전 고정 구조 검산

아래 네 기둥은 생극표와 선택 조건을 검산하기 위해 직접 만든 합성 구조다. 달력의 실제 입력과 별도로 다룬다.

| 원국 | 검토 방향과 고정 기대 |
|---|---|
| 甲寅·丙午·戊辰·庚申 | 목→화→토의 연간·월간·일간 경로, 화→토→금의 월간·일간·시간 경로를 함께 관측한다. 寅의 丙 정확근과 午의 丁 동오행을 구분한다. 寅申 충과 관련된 미평가를 유지한다. |
| 乙卯·丁卯·己卯·丁卯 | 목→화→토만 후보이며 매개의 정확근 없이도 표면의 연결이 성립한다. 구조 후보 상태를 유지한다. |
| 甲寅·庚午·戊辰·壬申 | 화가 장간에만 있다. 월지 午 본기의 丁으로 연결하는 목→화→토 구조 후보가 존재한다. |
| 甲寅·戊辰·己丑·壬子 | 화는 연지 寅의 기타 장간 丙으로만 관측된다. 목의 토 제어는 관측하고 목→화→토 구조 후보를 보류한다. |
| 甲子·庚辰·戊辰·壬申 | 화가 전혀 관측되지 않는다. 목의 토 제어에 대한 후보 오행을 제안하지 않는다. |
| 甲子·壬子·戊辰·丙午 | 연간 甲과 시간 丙 사이 거리 때문에 목→화→토 경로가 보류된다. |
| 甲寅·丙午·戊辰·癸亥 | 목→화→토의 표면 경로를 유지하고 戊癸합의 실제 작용을 미평가로 둔다. |
| 壬子·癸亥·壬子·癸亥 | 관측되는 수·목으로 상극 쌍이 성립하지 않는다. |

기존 사전 고정 생극표와 경로의 독립 테스트는 [통관 집중 검사](../../test/e5-tongguan.test.mjs)에 있다. 동일 원국의 양·음력 입력과 실제 원국의 목적별 일치·차이는 E5 실행 기록에서 별도 분모로 보고한다.
