# M4-C0 — 정관격 재·인 표면 위치 검토 정책 v0.1

선택 프로필은 `M4-ZHENGGUAN-WEALTH-RESOURCE-POSITION-REVIEW-V01` / `0.1.0`이다. 기존 M4 정관격 구조 후보에서 표면 재·인의 **위치 검토 문맥**을 판별한다. `재인 양불상애`, 실제 생조 전달, 성격·파격·구응을 확정하는 정책은 아니다. 기존 M4·M3·M2·계절·통근·지원 제한 정책을 소급 변경하지 않는다.

2026-11-13 KST에 아래 전사를 직접 확인했다. 현재 수락은 **제한적 위치 판단의 잠정 연구 GO / 실제 효력 판단 NO-GO**다. resolver 전에 독립 기대 사례를 고정하는 조건이 남아 있으며, 사례 동결 후 구현 GO와 실제 실행 결과는 별도 기록한다. 문헌 조사나 이 문서 자체를 코드·CLI·브라우저 검사 PASS로 세지 않는다.

## 채택하는 프로젝트 정의

- 부모 후보와 기존 M4의 월령 정관 후보 판정을 재사용한다. M4가 비후보이면 이 정관격 위치 판단은 적용 밖이고, M4의 문헌/정책 미정은 그대로 상속한다.
- 기존 M2가 일간 기준 정재·편재, 정인·편인으로 분류한 **연·월·시 표면 천간**이 대상이다. 정편을 함께 묶는 범위는 이번 위치 검토 정책의 선택이다. 장간 재·인은 원래 자료에 남기되 표면 양투를 대신하지 않는다.
- 위치 순서는 연→월→일→시다. 화면 배치와 배열 정렬로 바뀌지 않는다. 일간 자신은 재·인 대상이 아니다.
- 모든 표면 재×인 위치 쌍을 보존한다. 복수 쌍이면 전체 상태는 복수 문맥을 우선하고, 각 쌍의 글자·위치·중간 위치도 남긴다. 대표 한 쌍을 골라 나머지를 지우지 않는다.
- 재→인의 기존 오행 극 방향, 인접/격위, 표면 오합 및 관련 상관·칠살·지지 관계를 참조한다. 극 방향의 존재는 실제 파인·효력 소멸이 아니다.
- 같은 원국의 성별·M7·as-of·계절 대안이 표면 위치형을 바꾸지 않는다. 실제 입춘 부모 후보는 따로 검사하며 B 계절 대안 때문에 C1 결과를 복제하지 않는다.

**겹침 반례:** 연 재–시 인 사이 월간에 정관이 있으면 중간에는 월간 정관과 일간이 함께 있다. 따라서 `일간만 사이`와 `정관이 중간에 있음`을 구별한다. 후자의 중간 일간도 보존한다. 칠살은 정관 중개로 자동 대체하지 않는다. 다른 기둥의 정상 반복과 동일 참조의 오류 중복도 구분한다.

## 현재 검증 상태

현재는 원문 확인과 좁은 정책/결정표 수락까지다. 독립 fixture 동결, 구현, 공개/실제 자료/CLI/브라우저 실행과 정확한 SHA는 실제 수행 후 실행 기록에 추가한다. 기존 627개와 이전 M4 비공개 결과를 이번 새 코드의 검사로 가져오지 않는다. 원문·export·후보 a/b·2027 보강본은 읽기 전용이며 이번 문헌 검토에 KASI 호출·키·재수집은 없다.
