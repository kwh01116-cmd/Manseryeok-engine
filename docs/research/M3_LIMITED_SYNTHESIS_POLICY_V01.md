# M3 제한적 종합 판단 로컬 v0.1 — 무근·무인 조건의 좁은 약 분류

선택 프로필은 **`M3-LIMITED-ABSENT-ROOT-RESOURCE-SYNTHESIS-V01` / `0.1.0`**이다. 원국 전체의 구성·선택한 계절·통근·인성 제한 결과를 함께 검사하여, 아래의 폐쇄된 충분조건에서만 `WEAK_UNDER_SELECTED_POLICY`를 산출한다. 다른 경우에는 어떤 조건이나 효력 정책이 부족한지 구체적으로 보류한다. 신강·중화·종격·격국·용신·길흉은 이 프로필의 결론이 아니다.

이것은 기존 M3의 `finalStrength`를 바꾸거나 최종 해석/출시 게이트를 해제하는 경로가 아니다. 2026-11-12 사용자가 별도로 승인한 **명시적 로컬 연구 종합**이다. 충분조건이 맞지 않는다고 신강·중화·신약 아님으로 뒤집지 않는다. 기존 정책의 원래 의미와 미평가 필드를 유지한다.

### 원저·주석·프로젝트 가정

원저의 계절 단독 판단 비판은 계절의 왕·상·휴·수·사를 전체 강약으로 바꾸면 안 된다는 제한이다. 徐 주석은 표면의 동류가 반복되어도 실제 장간의 근이 없는 사례를 약으로 설명하며, 인성의 근과 일간의 근을 따로 본다. 기존 통근 정책이 기록한 음장생·전사 차이는 그대로 남긴다.

이 문헌이 아래의 정확한 조건식을 직접 제시하거나 모든 반례에 대해 증명한 것은 아니다. **프로젝트가 추가로 채택한 가정**은 다음과 같다.

> 선택 표에서 계절이 旺·相이 아니고, 원국 전체에 일간을 생하는 실제 표면/장간 요소와 일간의 장간 동오행 근이 없으며, 표면 동류도 모두 무근이고, 실제 설기·소모·제어 구조와 아래의 관계 제외 조건을 확인한 경우에는, 떠 있는 표면 동류만으로 이를 뒤집는다고 보지 않고 연구 정책의 약으로 분류한다.

이는 四辛卯·四丙申의 특정 문자열을 외워 반환하는 규칙이 아니다. 같은 정의를 만족하는 다른 천간·지지·날짜에도 일반적으로 적용하는 보수적 선택이다. 문헌의 사례에서 이 일반화를 채택했다는 사실과, 문헌이 이 일반화 전체를 직접 선언했다는 주장은 다르다. 비점수형 규칙이며 오행의 등장 수를 세력 다수결로 사용하지 않는다.

## 실제 충분조건과 종료 범위

각 부모 후보의 계절 대안마다 다음 조건을 **모두** 검사한다. 한 조건의 불충족·미확인을0이나 없음으로 대신하지 않는다.

| 조건 | 필요한 검사 | 충분조건에서의 역할 | 반대·보류 조건 |
| --- | --- | --- | --- |
| 완전한 같은 실행 입력 | 원국 네 기둥, 실제 모든 장간, M2/M3·통근·인성·계절과 출처/정책/후보 연결 | 존재·부재 판단의 전제 | 누락·sparse·외부 발급/다른 후보·변조는 입력 오류이며 약의 근거가 아님 |
| 계절 | 일간의 선택 상태가休·囚·死 중 하나 | 이 프로필이 허용하는 비旺·相 범위 | 旺·相은 범위 밖. 이것만으로 강을 뜻하지 않음. NEEDS_DATA/미정은 그대로 보류 |
| 일간의 실제 장간 근 | 선택한 네 지지 검사가 전부 유효하며 `ABSENT_UNDER_POLICY` | 일간의 구성상 지지 채널 부재 | 하나라도 PRESENT이면 효력·계절·반대 구조를 더 판단해야 하므로 이 충분조건을 적용하지 않음 |
| 인성의 완전 부재 | 연·월·시 표면뿐 아니라 모든 장간에서 일간을 생하는 오행이 없음 | 생조 전달 정책을 이 결론에서 필수로 하지 않을 수 있는 조건 | 장간 인성 하나라도 존재하면 표면 인성이 없어도 부재 아님. HELD인 표면 인성도 삭제하지 않음 |

| 기존 지지 쌍 관계 | 기존 M2가 검출한 관련 원국 쌍 관계가 없음 | 미평가인 관계 효과·근/지원 변화가 결론에 들어오지 않는 범위 | 검출된 합·충·형·해·파를 지우거나 약화시키지 않고 효력 정책이 필요한 보류 사유로 보존 |

이 충분조건은 신약의 필요조건이 아니다. 여기서 결론이 나지 않는 명식이 강하거나 중화라는 뜻이 아니며, 다른 정책이 같은 범위를 다르게 처리할 가능성도 남긴다. 종격·전왕·특수격을 추론하지 않는다. 반대 구조의 존재를 실제 강한 제압·정량 소모로 번역하지 않고, 네트워크·현재 PC 시각·LLM을 숨은 근거로 사용하지 않는다.

### 무엇이 중요하게 미정인지

| 입력 문맥 | 해당 결론에 중요한 미정 | 무관하게 일괄 차단하지 않는 미정 |
| --- | --- | --- |
| 모든 충분조건 충족 | 정확한 전통 일반화의 범위와 자료 정밀도는 한계로 공개 | 실제 근이 전혀 없으므로 근의 크기/손상 서열, 인성이 전혀 없으므로 그 인성의 전달·합 제한은 약 충분조건의 필수 계산이 아님 |
| 근 PRESENT 또는 인성 존재 | 실제 근의 효력, 인성의 작용·과다·다른 생극과의 관계 | 기존 존재/위치/십성 사실은 그대로 확정하여 제공 |

| 五合·지지 쌍·2구성원 이상 결합 | 원국 관계의 활성·효력·변화 | 기존 장간/통근을 삭제하거나 새 오행을 실제 원국으로 생성하지 않음 |
| 문헌 설명 충돌 | 선택할 해석·예외가 닫히지 않은 실제 쟁점 | 충돌 명식 문자열을 resolver에 하드코딩하지 않음 |

지지 암합·장간의 숨은 합·가상 합화는 이 프로필이 구현한 표면 五合/기존 관계 범위와 같지 않다. 표면 짝 부재를 **모든 전통 이론에서 합 가능성이 없다**고 설명하지 않는다. 이런 별도 이론의 효과를 요구하는 해석은 이 프로필의 범위 밖이며, 선택 정의의 구성원에 그 효과를 암묵적으로 추가하지 않는다.

## 보류와 조건부 경로

보류는 중화가 아니다. 자료 부족, 선택 계절의 미정, 프로필 범위 밖, 양쪽 구조의 병존, 필요한 효력 규칙의 미구현을 구분한다. 여러 사유가 있으면 하나를 고르려고 나머지를 삭제하지 않는다. 완전성 오류나 발급/참조 변조는 일반 보류와도 구분하여 거절한다.

| 상태 | 실제 의미 |
| --- | --- |
| `RESOLVED_UNDER_POLICY` + `WEAK_UNDER_SELECTED_POLICY` | 모든 좁은 충분조건을 충족한 경로의 연구용 약 분류. 전체 M3 게이트 READY가 아님 |
| `DEFERRED_MIXED_EVIDENCE` | 근 또는 인성이 있고 설기·소모·제어 구조도 있어, 어느 효과가 우세한지 이 프로필이 종합하지 않음 |
| `DEFERRED_EFFECT_POLICY_REQUIRED` | 관계/합 작용을 더 판단해야 하거나, 존재하는 근·인성의 실제 효력에 의존해야 함 |
| `OUTSIDE_POLICY_SCOPE` | 선택 계절이旺·相인 경우 등 이 약 충분조건이 적용되는 범위 밖. 강·중화 결론이 아님 |
| `NEEDS_DATA` | 이 경로에 필요한 자료가 부족함. 실제 부재나0으로 대신하지 않음 |

비旺·相 경로에서는 미평가인 표면 五合·지지 쌍·서로 다른2구성원 이상의 삼합/삼회를 먼저 보수적인 효력 보류로 처리한다. 그 뒤 근/인성과 반대 구조의 병존이면 혼재 보류, 근/인성만으로도 추가 효력이 필요하면 효력 보류, 모든 충분조건이 닫힌 경우에만 약 결론이다. 우선 상태와 별개로 다른 보류 사유와 모든 지원·반대 구조를 유지한다.

문헌/정책 충돌은 대표 사례의 수락 범위와 **수락하지 않은 충분조건**에 기록한다. 제35절의 명식 문자열을 외워 runtime `SOURCE_POLICY_CONFLICT`를 반환하지 않는다. 상충하는 하위 정책을 입력하거나 프로필과 개별 옵션이 다르면 명시적으로 거절한다.

입춘 등 기존 원국 후보가 둘이면 각 후보의 근·인성·반대 구조·관계를 따로 검사한다. 토왕 시작 표시 분에는 원국 하나와 통근·인성 결과 하나를 유지하면서 그 아래 계절 대안별로 충분조건을 검사한다. 서로 상관없는 후보를 곱하거나 첫 후보를 선택하지 않는다. 모든 경로의 결론이 같아도 경계 정보는 지우지 않는다.

규칙 ID·리터럴 사례와 실제 실행 결과는 구현 계약 및 실행 기록과 맞춰 고정한다. 이 문서의 정책 수락이나 사례 설계 자체를 실행 PASS로 표현하지 않는다.

## resolver와 분리한 사례 계약

대표 사례는 세 종류로 분리한다.

1. **문헌 문맥:** 제6절의 봄/가을 목 반례는 불완전 조건이므로 계절 단독 결론 금지를 검사한다. 四辛卯·四丙申은 전사에 실제 있는 무근 반례이며, 그 조건의 정책 일반화를 별도 표시한다. 제35절 `丙寅·戊戌·辛酉·戊子`는 원저/주석 해석 차이를 보존한다. 양력 출생일이나 누락 기둥을 보충하지 않는다.
2. **합성 정책 사례:** 충분조건, 근 또는 인성 하나 추가, 인성 채택 유보/통근 예외, 표면 부재·장간 존재, 반대 구조, 겹치는 관계, 누락·교차 후보·정책 불일치 등 각 분기를 구현 전에 리터럴 기대와 금지 결과로 고정한다. 완전 네 기둥을 사용하더라도 실제 역법상 출생 가능성을 별도로 확인하지 않았다면 합성으로 표시한다.
3. **현대 날짜 통합:** 기존 명식 계산기로 양력/음력 동등 입력, 입춘 두 후보, 토왕 시작의 한 원국/두 계절 대안을 실행한다. 이것은 규칙 해석의 외부 정답 인증과 구별되는 연결 검사다.

사례의 expected를 resolver 출력에서 생성하지 않는다. AI 구현자와 반례 검토자의 분리는 구현값과 독립된 계약 검토이지 인간 전문가·독립 학파·과학적 예측 검증이 아니다. 기존 계절·통근·인성 제한의 독립 기대값은 새 충분조건에 맞추어 바꾸지 않는다.

## 완료와 미완료의 표시

완료라고 하려면 위 조건을 실제 소비하는 일반화된 순수 resolver, 조건이 맞는 결론 사례와 비슷하지만 보류되는 사례, 후보/참조 검증, 입력부터 한국어 리포트, 기존 회귀와 실제 자료 연결 실행이 있어야 한다. 전부 보류하는 껍데기를 완료로 부르지 않는다. 상태별 비율을 맞추기 위해 조건을 낮추지 않는다.

이번 프로필의 완료와 별개로 신강·중화의 충분조건, 일반적인 근력·생조/설기/제어의 효력 비교, 관계 작용, 사령·조후·격국·용신·길흉은 미완료다. 기존 기본 엔진/G0/G1-P2, M3 전체 해석·상용 출시 게이트, 출생/역사시/2027 조회 범위와 M7 정책을 바꾸지 않는다.
