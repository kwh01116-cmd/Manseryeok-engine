## 공개 문서의 확인 수준과 채택 제외

- [KASI 월력요항](https://astro.kasi.re.kr/life/post/almanac)은 일부 접근거부 표면과 함께 발표 주체/관보 안내를 읽을 수 있었다. 연간 태양 runtime을 이 표면에서 채우지 않았다.
- [KASI2027 달력자료](https://astro.kasi.re.kr/kor/life/post/calendarData?search_year=2027)는 직접 본문을 읽었다. V1.0a/2026-06-30 12:33, 음력 월초/대소와24절기 표가 있으며 공식 발표 자료가 아니라는 주의 문구가 있다. 기존 API 원문과 소한·입춘·경칩·입하·대설 분 표기를 대조했지만 웹 표를 API의 출처로 바꾸지 않았다.
- [KASI2028 달력자료](https://astro.kasi.re.kr/kor/life/post/calendarData?search_year=2028)는 직접 본문에서 V1.0a/2026-06-30 11:33, 예비 자료 주의 문구를 확인했다. 소한2028-01-06 04:55·입춘2028-02-04 16:31은 **확인한 웹 표의 값**이며 이번 승인 API corpus에 편입하지 않았다.
- [KASA2027 공고](https://www.kasa.go.kr/bbs/BBSMSTR_000000000018/B000000003234Li6nD2.do?mno=sub01_03_03)의 공고일2026-06-29/제2026-0078호/공공누리2유형 표기는 primary 검색 본문에서 확인했다. direct open은 실패했으므로 원문 HTML/PDF 직접 수락으로 표시하지 않는다. 별도 원래 출처 등록부에도 해당 권리 구분이 있다. 고시·보도자료·KASI 예비표·OpenAPI 라이선스를 혼합하지 않는다.

웹 문서 열람은 새 KASI API 호출과 다르며, 이번 자료 조사·연간 재정규화의 API 요청/키 사용은0이다. 권리와 공식 판본 확인 수준은 [권리 감사](KASI_DATA_RIGHTS_DISTRIBUTION_AUDIT_V01.md)에 별도로 남긴다. 기관에는 연락하지 않았다.

## 검증과 남은 최소 조치

연간 로더의 공개 합성 원문 검사6/6은 첫 실행 PASS이며 실제 API 수집 인증이 아니다. 원본24행의 실제 재정규화·기존 두 분과의 일치·출처 연결 검사는 private 리뷰 후보와 실제 원문 조사 영수증으로 분리했다. 새 월운의 고정2026/2027 간지 기대·모든12절 전/동분/후·기존 공통 연도 의미 연속·2028결손·UTC/Seoul 검사는7/7 PASS다. 합계13/13(fail/cancel/skip/todo0)을 고정Node22.23.3에서 실행했고, 두 테스트 파일을 함께 실행한 첫 시도에 실패는 없었다. 실제 제품/오프라인 결과와 최종 코드 SHA·실행 수는 실행 기록에서 최종 확인한다.

개발 중 실제 API 자료 연결 파일럿에서 기존2026표의 완료10행이 새 정책에서는12행으로 바뀌었다. 끝 두 구간은 `2026-12-07T11:53 → 2027-01-05T23:10`, `2027-01-05T23:10 → 2027-02-04T10:46`이었다.2027표는10행 완료/2행 NEEDS_DATA를 유지했고, 입춘10:45/10:46/10:47 조회는 각각 丙午·辛丑 / 상관된 두 대안 / 丁未·壬寅이었다. 이 파일럿은 출생M1호출0·API요청0이며 최종 SHA의 전체 제품/오프라인 검증과 구분한다. 영수증은 `.private/sprint4-20261115-future/real-monthly-pilot.json`이다.

2027 음양력 전체 및2028 연결을 닫는 최소 자료는2027 일별 음양력 원문과2028 소한/입춘의 출처·분 표기·시계 정책이다. 외부API 재수집이나 웹 표의 생산 데이터 편입이 필요하면 자료군·호출/다운로드 범위·권리·독립 비교·새 별도 지문을 정해 사용자 승인을 받은 뒤 수행해야 한다. 현재 미확정을 금지 확정으로 바꾸거나 자료 없는 기능을 지원으로 표시하지 않는다.
