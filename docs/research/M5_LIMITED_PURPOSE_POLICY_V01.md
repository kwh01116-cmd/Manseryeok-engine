# M5 v0.1 — 겨울 목 일간의 온기 요소 검토

정책 `M5-WINTER-WOOD-WARMING-CANDIDATE-V01` / `0.1.0`, 목적 `WINTER_WOOD_WARMING_REVIEW`. 이는 명시적으로 선택하는 **한 목적의 후보 정책**이다. 조후 전체·억부·격국의 최종 용신이나 희신/기신 순위가 아니다. 과학적으로 측정한 추위·온기·예측 효력도 아니다.

## 확인한 근거와 채택하지 않은 범위

2026-11-14 [NCC 《子平真詮評註》第三卷](https://ncc.com.tw/fate/paleo/bg/bg_033.htm)의 「十四、論用神配氣候得失」 본문을 직접 읽었다. 沈孝瞻 원저의 겨울 목·화 문맥은 화가 일간의 설기와 다른 조후 역할을 가질 수 있음을 설명한다. 같은 절의 徐樂吾 주석은 겨울 목과 丙丁을 연결하며 사례를 덧붙인다. 원문의 격 성립·강약 조건과 주석의 귀천·인물 이야기는 이번 계산의 정답으로 사용하지 않는다.

원문은 화가 있는 구성의 해석도 다룬다. 이를 **화가 없으면 언제나 화를 더해야 한다는 충분조건으로 역전하지 않는다.** 아래의 무화 후보와 유화 보류는 제품이 선택한 좁은 `PROJECT_POLICY`다. 실제 효력 판단은 별도로 남긴다.

같은 절에서 겨울 금수상관의 화와 실제 채택 요소가 다를 수 있다는 주석, 여름 목의 수·인성 문맥도 확인했다. 이들은 서로 다른 조건과 예외를 요구하므로 겨울 목의 단순 반대 규칙이나 전월령 조후표로 합치지 않았다. [시자 전사](https://dao.time.actor/ziping-zhenquan-pingzhu/juan-3)는 NCC를 참고 자료로 명시하므로 두 사이트를 독립 학파의 합의로 세지 않는다. 원문/주석 구분을 대조하는 보조 표면으로만 사용했다. 스캔·비평 판본·권리는 미확인이다.

[동리 제3727절](https://www.donglishuzhai.net/chapter/3727.html)은 직접 접속502였고 검색 캐시의 표면·갱신 표기2021-02-06은 보조 확인 수준이다. 캐시에는 겨울 금/수 교정 주기가 있으므로 이번 규칙의 직접 충분조건으로 채택하지 않았다. 접속 실패를 원문 대조 성공으로 표시하지 않는다.

기존 감사의 [korean_saju 고정 revision `8c81256…`의 johu.py](https://github.com/glee1228/korean_saju/blob/8c81256db10d3179d31f551beacaa69f2ab2fcc5/src/korean_saju/saju/johu.py)를 실제 읽었다. 월지 계절 점수에 화/수 표면 개수와 합국 보정을 더하고 임계값으로 화/수·절실도를 정한다. 그 배점·합화 가정·수치 절실도는 문헌이 정한 정량값으로 볼 근거가 닫히지 않아 가져오지 않았다. 외부 소스·패키지를 생산 코드에 복사하거나 외부 역법을 도입하지 않았다.

유화 보류는 화가 불리하다는 판정이 아니다. 무화 후보는 부족량 측정이나 화 추가 처방이 아니다. 보류일 때도 기존 화·인성·근·격국 후보를 삭제하지 않는다. `candidateElements=[]`는 이 정책이 후보를 자동 채택하지 않았다는 뜻이다.

대상 천간×월지의 기호 조합은 10×12 중 **4개(甲亥·甲子·乙亥·乙子)**다. 이것은 실제 출생자 적용률이 아니다. 그 안에서도 기존 화나 자료/조건 미확정 때문에 보류할 수 있다. 특히 12:00 午시의 장간 丁도 화 존재로 취급하므로 일반 정오 사례를 무조건 후보로 만들지 않는다.

## 입력·참조·독립성

`deriveM5LimitedPurpose(evidence,{policyId,m2Facts,seasonal,innerPatterns?})`는 CLI 밖의 순수 TypeScript 함수다. 새 달력·십성·장간표·왕상휴수사표를 만들지 않는다. 기존 M3/M2의 동일 발급 문맥, 네 지지의 기존 장간 구성 완전성, 발급된 Sili 계절 판단과 실제 일간/월지/절입·fact/evidence 참조의 일치를 검사한다.

로컬 어댑터는 기존 `validateLocalM3SeasonalJudgments(seasonal,{evidence})`로 계절 envelope의 실행 연속성도 확인해야 한다. 순수 모듈의 구조/값 비교를 외부 출처 인증이나 G0 receipt로 표시하지 않는다. 모든 계산 자료 참조와 명리 문헌/프로젝트 source를 구분한다.

출력은 목적·정책/버전·parent candidate·후보/보류·조건표·실제 화 위치·판단 과정·반대/미정 근거와 fact/member/evidence/rule/source 참조를 포함한다. 월령 OTHER도 실제 존재 검사에는 포함하지만 MAIN/OTHER를 힘의 가중치로 바꾸지 않는다. 없는 화를 납음·합화·삼합의 가상 오행으로 만들지 않는다.

기존 M4의 정/편인 등 구조나 기존 M3 근·계절/점수는 이 조후 후보를 최종 용신으로 승격시키지 않는다. 겹치는 관계는 반대/미평가 문맥으로 보존하고 삭제·합화하지 않는다. 입춘의 서로 다른 부모는 각각 판단하고, B의 계절 대안은 부모 아래 그대로 둔다. 성별·운의 조회 시각·M7 투영·실험 강약 점수는 입력으로 소비하지 않는다.
