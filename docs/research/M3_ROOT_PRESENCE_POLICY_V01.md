# M3 구성상 통근 성립 — 장간 동오행 정책 v0.1

명시적 정책 **`M3-ROOT-PRESENCE-HIDDEN-SAME-ELEMENT-V01`**, 조합 버전 **0.1.0**이다. 기존 `M2-HIDDEN-STEMS-CLASSIC-MEMBERS-MAINQI-V1`의 장간 구성과 천간 오행을 재사용한다. 선택한 표에서 대상 표면 천간과 **같은 오행의 장간이 존재하는가**를 실제 판정하며, 근력·효력·생조 전달·최종 신강약을 판정하지 않는다. 다른 통근 이론의 보편적 대체물이 아니다.

## 실제 확인한 자료와 저자 구분

접속일은 **2026-11-12 KST**다. NCC는 『子平真詮評注』의 저자를 沈孝瞻 원저·徐樂吾 평주로 표시한다. 해당 단락의 HTML은 본문과 주석에 서로 다른 표지를 주지 않는다. 아래 귀속은 별도의 무주석 전사 본문과 대조한 **전사 수준의 구분**이며, 인쇄본 대조나 문헌 계보 인증이 아니다.

「論十干十二支」의 서락오 주석은 甲乙이 寅卯뿐 아니라 亥未辰의 근을 공유한다고 설명하고, 일간 자체의 근과 인성의 근을 따로 논한다. 「論陰陽生死」의 주석은 실제 장간을 근거로 들며, 일간에 대한 논의를 연·월·시 천간에도 적용한다고 명시한다. 이를 이번 네 표면 천간 검사와 인성 자체 근 연결의 **문헌 문맥**으로 삼는다. 인성 유근이 실제 생조를 보장한다는 후속 결론은 가져오지 않는다.

원저와 주석은 같지 않다. 「論陰陽生死」의 원저 대응 단락은 음양 장생과 묘의 차이를 논하지만, 주석은 음간 장생 때문에 장간이 늘거나 줄지 않는다고 비판한다. 「論十幹得時不旺失時不弱」도 실제 저장 오행과 뿌리를 연결하는 예를 들면서 음장생의 근을 인정하는 표현이 있고, 주석은 乙午·丁酉를 근으로 보는 설명에 이의를 제기한다. **이번에는 십이운성만으로 근을 생성하지 않는 제한 정의**를 선택한다. 본문의 근 강약 비교·비겁 수량 비교·계절 사령·종격·길흉은 실행하지 않는다.

### 그대로 남기는 전사 차이

- NCC 제1절에는 근/인성 관련 문장이 연속 중복되고, 甲乙皆本이라는 표기와 연월 천간 예의 빈 글자가 보인다. 중복 제거·교정 판본 확보를 했다고 기록하지 않는다.
- 제6절의 甲 예에서 NCC는 亥子寅卯, 東里 본문 캐시는 亥寅卯로 표시한다. 현재 장간 정책에서 子는 癸뿐이므로 **甲/子는 직접 목근 없음**이다. NCC의 子를 근거로 기존 표에 목을 추가하지 않는다.
- 음장생 단락은 NCC의 明根과 東里의 有根 표기가 다르다. 주석의 비판과 함께 남기며 한 원문으로 조용히 통일하지 않는다.
- 東里의 中州本 교감 표시는 그 사이트의 주장이다. 이번 작업이 中州本·원서 스캔·비평 판본·권리·독립 예측 효력을 검증한 것은 아니다. 공개 전사 페이지의 일치도 독립 학파 합의를 뜻하지 않는다.

규칙 ID는 **`M3-RULE-ROOT-PRESENCE-SAME-ELEMENT-001`**이다. 기존 장간 규칙 `M2-RULE-HIDDEN-STEMS-001`과 그 출처는 별도 의존성으로 남긴다. 기존 M2의 일곱 null native 버전에 이 모듈의0.1.0을 채워 넣지 않는다. KASI는 계산 자료 출처이고 통근 정의의 문헌 출처가 아니다.

이번 결과의 `rootPresence`는 정책 아래 판정값이다. `rootEfficacy`·`rootStrength`는 `NOT_EVALUATED`, `finalStrength`는 `NOT_IMPLEMENTED`다. 기존 구조 근거의 `rootCandidates`와 미해결 효력 의미를 소급 변경하지 않는다. 선택 옵션이 없으면 기존 결과를 유지한다.

## 독립 기대값과 실제 연결 검사의 차이

단위 검사는 기존 승인 장간표를 사람이 대조한 **120개 천간×지지 리터럴 기대값**으로 존재·매칭 장간·일치 유형·MAIN_QI/OTHER를 검사한다. 甲寅/甲卯/乙寅/甲辰, 丙戌/壬丑/戊午/丙寅의 성립과 甲子/丁酉/乙午/辛辰의 불성립은 이 정의의 대표 반례다. 기대값을 검사 대상 resolver나 같은 오행 helper로 생성하지 않는다. 120개를 실제 출생 명식이나 학파 전체의 정답으로 표시하지 않는다.

독립 표의 수동 집계는 성립56·불성립64이며, 매칭56개는 정확 천간28·다른 음양의 동오행28, 본기24·기타32로 나뉜다. 이는 규칙 단위 표의 집계이며 실제 명식의 유근 비율에 맞추는 목표값이 아니다. 두 음양 천간이 공유하는 지지는 목: 寅卯辰未亥, 화: 寅巳午未戌, 토: 丑寅辰巳午未申戌, 금: 丑巳申酉戌, 수: 子丑辰申亥다. 이 목록은 새 장간표가 아니라 기존 정책에서 독립 기대값을 검토한 체크 목록이다.

어댑터 검사는 네 대상·네 지지 완전성, 동일 글자의 위치 분리, 일지 장간 포함, 중복 연결·누락·sparse·교차 후보/정책/출처·변조 설명 거절과 같은 실행의 M1→M2→M3 연결을 확인한다. 순수 모듈은 외부 API 진위를 인증하지 않는다.

실제 비공개 입력 검사는 이미 검증된 로더와 고정 지문을 사용해 양력/음력 의미 일치·절입 후보·토왕 B 대안·정책 교대·요청 격리를 확인한다. 이는 자료와 새 판단의 **연결 정확성 검사**이며 문헌 해석·근의 실제 세력·예측 타당성의 독립 인증이 아니다. 실제 건수·실행 SHA·실패·브라우저 회귀는 실행 보고서에서 별도로 기록한다.

기본 엔진/G0/G1-P2와 M3 최종 해석·출시 게이트, 기존 계절·M7 정책, 출생·역사시·2027 조회 범위는 유지한다. 이번에는 KASI 요청·키·재수집·LLM·새 UI·공개 배포가 없다.
