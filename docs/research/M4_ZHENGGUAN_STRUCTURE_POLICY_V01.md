# M4 정관격 구조 분석 v0.1 — 월령 후보와 성패 조건의 구분

선택 정책은 **`M4-ZHENGGUAN-MONTH-STRUCTURE-V01` / `0.1.0`**이다. 기존 명식 후보와 M2의 월지·장간·십성을 이용해 정관격 **구조 후보**와 성패 관련 **관측 조건**을 분류한다. 최종 `格成`·`格敗`·`救應`, 좋은 사주, 용신 추천을 반환하는 정책이 아니다.

이 문서는 2026-11-13 KST에 확인한 문헌과 프로젝트의 구현 정의를 구분한다. 정책 수락이나 사례 설계 자체는 코드 실행 PASS가 아니다. 실제 검증 SHA·분포·실패와 전달 결과는 별도 실행 기록에 남긴다.

또한 NCC 제10절의 사정지 설명과 기존 M2 장간 정책은 전체 구성에서 같지 않다. 예를 들어 기존 M2의 午에는 丁·己가 있다. 이 작업은 기존 M2를 재사용하는 선택 정책이며, NCC의 장간표 전체를 옮겨 동일하게 재현했다고 하지 않는다. M2 구성원을 삭제하거나 추가하지 않는다. 특히 午의 OTHER 己가 정관인 경우는 이 차이의 적용 범위를 닫지 못했으므로, 투출 여부와 무관하게 `SOURCE_OR_POLICY_UNRESOLVED`로 남긴다. 午의 MAIN 丁 정관이나 다른 월령까지 함께 미지원으로 만들지 않는다.

## 고정하는 의존 계약

- 기존 M2 로컬 프로필 `m2-basic-classification-local-v1`의 실제 장간 정책 `M2-HIDDEN-STEMS-CLASSIC-MEMBERS-MAINQI-V1`을 사용한다.
- `M2-RULE-HIDDEN-STEMS-001`의 원래 버전은 `1.0.0`이다. 다른 기존 규칙의 native 버전이 null이면 새 M4의 `0.1.0`으로 채우지 않는다.
- `MAIN_QI`는 기존 정책이 이름 붙인 본기 속성이다. 실제 사령 일수·강도·오행 점수·득령의 증명이 아니다.
- 정관·칠살·재·인·상관은 기존 M2 십성 결과를 사용한다. 장간·십성·오합표를 새로 복제하지 않는다.
- 계산 출처는 기존 API 명식·절입 참조이며, 명리 해석 규칙의 출처와 분리한다. KASI를 격국 규칙의 저자로 쓰지 않는다.
- M3의 계절·통근·지원·종합 결과는 선택했을 때 원래 의미로 병렬 보존한다. M4 구조 후보를 계산하는 데 최종 강약 판단이나 M7 입력을 필수로 하지 않는다.

## 후보 결정표 — 이 버전이 실제로 선택하는 범위

여기서 정관은 **해당 후보의 일간을 기준으로 한 기존 십성 분류**다. 현재 명식의 절입 월지와 모든 월령 장간을 검사한다. 다른 후보의 월지·일간·장간을 끌어오지 않는다.

| 월령의 정관 구성 | 표면의 정확한 같은 천간 | 후보 판정 | 따로 남기는 검토 |
| --- | --- | --- | --- |
| MAIN_QI가 정관 | 있음 또는 없음 | `STRUCTURAL_CANDIDATE` — MAIN 근거 | 투출 유무·위치를 그대로 표시한다. 투출하지 않았다고 본기 후보를 지우지 않는다. |
| 午의 OTHER 己가 정관 | 있음 또는 없음 | `SOURCE_OR_POLICY_UNRESOLVED` | 기존 장간·정관·투출 사실은 보존한다. 사정지 본문과 M2 표의 호환 정의를 이 버전에서 선택하지 않았다. |
| OTHER에 정관이 있음 | 있음 | `STRUCTURAL_CANDIDATE` — EXPOSED_OTHER 근거 | 본기가 정관인 경우와 타입을 구분한다. 격 변화의 실제 성립은 확정하지 않는다. |
| OTHER에 정관이 있음 | 없음 | `NOT_A_CANDIDATE_UNDER_POLICY` | 월령 속 정관 존재는 보존한다. 미투출 OTHER를 취하는 사령·회합·변화 정책은 이 버전에서 선택하지 않았다. |
| 월령 장간에 정관이 없음 | 원국 다른 곳에 있어도 무관 | `NOT_A_CANDIDATE_UNDER_POLICY` | 원국의 정관 존재 A와 월령 기반 후보 B를 구별한다. |
| 필수 후보·장간·십성·참조 누락 또는 변조 | 판단하지 않음 | 입력 오류/자료 미완으로 구분 | 누락을 정관 부재로 바꾸지 않는다. |

표의 午 OTHER 호환성 보류를 일반 OTHER 판정보다 먼저 적용한다. 이는 자료 누락이나 엔진 오류가 아니라 해당 문헌 조합의 선택 정책 미정이다. 정확 투출/표면 일치 목록은 네 표면을 모두 검사한다. 같은 오행의 다른 음양이나 다른 기둥의 지지 대표 오행은 정확 천간 투출이 아니다. 원국의 정상 반복 위치는 각각 보존한다.

**경쟁 선택은 별도 필드다.** 정관 이외의 월령 장간이 연·월·시 표면에 정확하게 드러나면 그 위치를 경쟁 검토 대상으로 보존한다. 이때 정관 구조 후보를 삭제하거나 경쟁하는 모든 격이 실제 성립했다고 하지 않는다. 일간 자체와만 일치하는 월령 장간은 일치 사실을 남기되, 그것만으로 비견격 경쟁을 생성하지 않는다. 이 위치 범위와 단독 취격 보류는 이번 프로젝트의 좁은 구현 정의다.

다른 월령 장간이 드러나지 않았다는 사실도 정관격의 최종 성립을 보장하지 않는다. 반대로 복수 노출이 있다는 이유만으로 정관 후보를 false로 바꾸면 제10절의 겸격 문맥을 손상할 수 있다. 전체 격국 사이의 선택·변화·우선순위는 이 v0.1의 지원 범위 밖이다.

## 관련 조건 C와 실제 효력 D

후보 상태와 아래 조건의 관측 상태를 한 라벨로 합치지 않는다. 원국에 정관이 있지만 월령 후보가 아닌 경우에도 A와 관련 위치를 보존한다.

| 관측하는 구조 | 실제로 연결할 자료 | 이번에 확정하지 않는 것 |
| --- | --- | --- |
| 재성의 官 생조 방향 | 모든 정재·편재의 표면/장간 위치와 정관 기준 요소 | 재성이 있다는 이유만으로 官이 충분히 강하거나 成格이라고 하지 않는다. |
| 官→印→日主의 방향 | 모든 정인·편인 위치와 官·일간의 오행 관계 | 인성 존재를 실제 전달·자동 救應으로 바꾸지 않는다. |
| 상관과 정관의 병존·극 방향 | 실제 상관·정관 위치와 기존 십성 fact | 상관견관 검토 구조를 즉시 破格으로 바꾸지 않는다. |
| 정관과 칠살의 병존 | 표면과 장간을 구별한 위치 목록 | 숨은 칠살과 표면 혼살의 효력을 같게 두지 않고, 무조건 혼잡 실패라고 하지 않는다. |
| 정관이 참여하는 오합 | 실제 상대 천간·기둥 위치·인접/격위와 모든 짝 | 본신 합·타간 합·경쟁·통근 예외를 해결하지 않은 채 官 삭제·合去·合化를 선언하지 않는다. |
| 재·인의 위치와 경쟁 요소 | 정확한 위치, 중간 기둥, 표면/장간 구별 | 떨어져 있다는 이유만으로 상극이 사라졌다고 하지 않는다. |
| 기존 지지 관계와 삼합/삼회 구성 | 모든 관련 쌍·겹침·부분/완전 구성원과 월지 연관 | 형·충·해·파·합 하나로 다른 관계를 삭제하거나 실제 근 손상·변화·구응을 확정하지 않는다. |

후보가 있고 재·인 관련 구조가 확인되면 성격 관련 조건을 **관측했다**고 출력할 수 있다. 방해·경쟁 조건도 같은 수준으로 출력하며, 어떤 조건이 없다고 그 효과를 0으로 계산하지 않는다. 정확한 成格·破格·救應·격국 품질은 `NOT_IMPLEMENTED`, 조건의 실제 효력은 `EFFECT_POLICY_REQUIRED` 또는 동등한 명확한 상태로 남긴다. 최종 라벨을 보류했어도 확인 가능한 후보까지 모두 미정으로 되돌리지 않는다.

## 사전 사례와 문헌 반례의 사용

사례 파일은 resolver 구현 전에 기대값·금지 추론·출처·정책·이유를 리터럴로 고정한다. 문헌의 네 기둥, 합성 명식, 실제 API 출생일의 검증 수준은 구별한다. 누락된 문헌 기둥이나 양력 생일을 만들지 않는다.

- 薛 예 `甲申·壬申·乙巳·戊寅`: 제31절의 월령 정관, 재·인 위치 사례다. 기존 M2에서 申의 庚이 MAIN 정관이지만 표면 庚은 없다는 조건을 검사한다. 본문의 고위·사건 평가는 정답이나 기능으로 사용하지 않는다.
- 李 예 `庚寅·乙酉·甲子·戊辰`: 酉의 MAIN 辛 정관과 표면 庚 칠살·乙庚 짝을 보존한다. 乙庚합에 따른 관살 정리의 실제 효력은 기대값으로 쓰지 않는다.
- 金 예 `乙卯·丁亥·丁未·庚戌`: 원저의 정관 절 배치와 徐의 印格 쪽 해석에 차이가 있다. 후보의 구조와 격 변화·최종 해석의 미정을 구별하는 반례다.
- 宣 예 `己卯·辛未·壬寅·辛亥`: 기존 M2의 未 본기는 己이므로 MAIN 정관과 년간 己의 정확 투출로 검사한다. 원문의 雜氣·用事 문맥을 M2의 OTHER와 동일시하지 않는다.
- 辛일 寅월 丙 투출, 여기에 甲도 투출하는 제10절의 부분 문맥은 OTHER 정관과 경쟁을 뒷받침하지만 완전 네 기둥으로 보충하지 않는다.

문헌 조사 중 宣 예의 己와 范 예의 `丁丑·壬寅·己巳·丙寅`에 있는 甲을 OTHER라고 잘못 설명했다. 독립 사례 담당자가 기존 표와 대조해 각각 未의 己, 寅의 甲이 MAIN임을 지적했고, resolver 작성 전 계약을 정정했다. 문헌의 장간 언급이나 雜氣라는 말만으로 우리 표의 MAIN/OTHER를 추정하지 않는 반례로 남긴다. 기존 M2 표나 기대값을 잘못된 설명에 맞춰 바꾸지 않았다.

## 실행·참조·출시 경계

핵심 함수는 CLI 밖의 순수 모듈로 둔다. 기존 로컬 발급 명식·M2·구조적 M3를 재사용하며 출생 M1은 요청당 한 번이다. 일반 JSON의 `status=OK`를 외부 진위 인증으로 신뢰하지 않는다. 후보→M2 fact→M4 조건→설명의 참조와 원래 계산 정책·자료 지문을 보존한다.

입춘의 두 원국 후보는 각각 계산한다. 토왕 B 표시 분의 한 원국 아래 계절 대안 둘은 월령 장간을 바꾸지 않으며 M4 후보를 중복 생성하지 않는다. M3의 강약 보류는 M4 구조 분석의 실패가 아니고, 기존 좁은 신약 결과도 일반 강약으로 승격하지 않는다.

옵션을 선택하지 않은 기존 결과와 `finalStrength=NOT_IMPLEMENTED`, 기본 엔진/G0/G1-P2·기존 M3 전체 출시 게이트를 유지한다. M4의 후보가 관측됐다는 이유로 격국 전체나 상용 해석을 READY로 바꾸지 않는다. M5 용신, M6 종격·합화, 길흉·예측, 역사시·지원 연도 확대는 이번 범위 밖이다.
