# E6 원국과 운의 구성 관계

`E6-NATAL-TRANSIT-M2-MEMBERSHIP-V01/0.1.0`은 발급된 한 원국 후보와 그 후보에 적용되는 한 시점 대안을 평가한다. 각 위치를 한 번씩 등록하고, 한 쌍은 서로 다른 두 위치로 구성한다. 원국의 연·월·일·시, 적용 중인 대운·세운·월운은 독립 위치다. 한 컨텍스트에서는 한 운 층에 한 기간만 활성일 수 있다.

| 관계 | 위치와 범위 |
|---|---|
| `NATAL_NATAL` | 원래 원국 네 위치의 관계 |
| `NATAL_TRANSIT` | 원국 위치와 활성 운 위치의 관계 |
| `TRANSIT_TRANSIT` | 같은 조회 대안에서 동시에 활성인 운 위치 사이의 관계 |

## 관계표와 역할

천간 오합과 지지 육합·육충·형·파·해를 기존 M2 함수로 조회한다. `巳申`에는 합·파·형을 모두 기록한다. 자형은 서로 다른 두 위치가 필요하다. 도표에 붙은 원전·현대 관행 출처와 방향 표지를 유지한다. 원국의 연월일시 거리에서 정의한 효력 조건은 시간축에 적용하지 않는다. [지지 관계표](../../src/domain/branchRelations.ts) · [천간 오합표](../../src/domain/stemCombinations.ts)

활성 운의 천간·장간 십성과 지지 십이운성은 해당 원국의 일간 기준이다. 표면 천간과 각 지지의 본기·기타 장간을 별도로 반환한다. E1 세력 배분과 기존 억부·조후·격국·통관의 분석은 원국에 고정된다. [지장간표](../../src/domain/hiddenStems.ts) · [십성 분류](../../src/domain/tenGods.ts) · [십이운성](../../src/domain/twelveGrowthStages.ts)

## 삼합·삼회 구성

정의별로 서로 다른 두 구성원부터 관측한다. 모든 구성원의 위치 배열을 보존하므로 같은 글자가 여러 위치에 있어도 두 종류로 세지 않는다. 원국 부분 구성에 새 지지가 들어오면 `COMPLETES_NATAL_PARTIAL`, 이미 원국에서 완성된 구성에는 `NATAL_ALREADY_COMPLETE`를 반환한다. 후자의 `includesNewNatalCompletion`은 false다. 원국만의 구성, 원국과 운의 구성, 운만의 구성을 각 범주로 조회한다. `namedElement`는 표에서 지정한 오행 이름이다. `effectStatus`는 미평가다. [삼합·삼회 유한표](../../src/domain/triadMemberships.ts)

## 두 시점의 동일성

쌍별 `key`는 범주·종류·방향·각 위치의 인스턴스를 결합한다. 원국은 원국 후보와 연월일시 역할 및 간지로, 운은 후보와 운 층·기간의 안정된 `periodRef`·간지로 식별한다. `shapeKey`는 위치 인스턴스 대신 관계 종류·방향·기호로 비교한다. 따라서 같은 세운이 유지되는 동안 월운이 교체되어도 원국–세운 관계는 유지된다. 반대로 간지와 형식이 같은 새 월운이라도 별도 기간이면 이전 관계 종료와 새 관계 추가가 각각 기록된다.

삼합·삼회의 변화는 범주와 정의에 맞춰 시간축 전후의 구성원과 인스턴스를 비교한다. 쌍의 대조에 필요한 운 층이 미확인인 경우 `uncomparable`로 보내며, 확인 가능한 다른 운 관계와 원국 관계는 계속 대조한다. 운이 포함된 삼합·삼회의 전체 구성은 조회 쪽에 미확인 층이 있으면 `UNCOMPARABLE`을 반환하고 두 시점의 관측 구성은 남긴다. 데이터가 완전하고 지정 관계표에 적중이 없으면 `OBSERVED_NO_RELATIONS`를 반환한다. 활성 운이 없는 것으로 확인된 경우와 계산을 할 수 없는 경우의 구별은 시간 컨텍스트에 따른다.

운 간지가 발급됐고 기간 경계만 `NEEDS_DATA`인 층은 확인한 관계를 반환한다. 기간 전체에 대한 판단은 부분 상태다. 같은 기간 인스턴스의 관계가 양쪽에서 확인되면 유지로 기록한다.

관계 엔진은 같은 발급 원국 객체와 정책을 가진 두 관측만 대조한다. E6 어댑터가 양립하는 경계 대안을 골라 각 대조를 수행한다. 공개 API 입력은 출생자료와 조회 시점으로 한정한다. 관측 관계가 추가되거나 종료되어도 사건·길흉·합화·합거·근 손상 또는 최종 용신의 변동을 산출하지 않는다.
