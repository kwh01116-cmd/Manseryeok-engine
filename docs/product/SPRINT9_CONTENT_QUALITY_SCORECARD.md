# 베타 판정표 · 인간 응답 수집 전 사전 등록

**판정 단위**는 사례·후보·claim·자료 버전이다. 개발 환경에서 측정할 수 있는 입력·출력 정합성과 실제 사람이 느끼는 가치를 각각 기록한다. 같은 명식의 시각·경계 반복, 서버 재실행, 두 시간대 일치는 독립된 독자 또는 독립된 학파 검증이 아니다.

| 등급 | 재현 조건 | 조치·재개 조건 |
|---|---|---|
| P0 | 잘못된 원국·정보 유출·판매 차단 우회·미지원 결론 확정·중대한 무결성 오류 | 실제 베타 즉시 중단. 원인과 영향을 보존하고 원래 입력·반례·권한 검사로 재확인. 담당자의 재개 검토 필요 |
| P1 | 후보 혼입·정책 근거 불일치·의미 반전·반복적 오해석·보관/복구 실패 | 해당 기능이나 문장 보류. 사실/정책/서술 중 원인을 나눠 수정. 같은 입력·대조 입력으로 재검토 |
| P2 | 추상어·역할 반복·긴 면책·전문 용어·읽기 불편 | 독자가 지목한 문장·장·원국을 보존. 동일 claim 문체 실험이나 중복 참조 표기를 검토. 인간 재검토 전 개선 효과 미확정 |

## 세 가지 콘텐츠 실험

1. **추상적인 해석.** 같은 명식, 같은 영역, 실제 해석·일반 설명·다른 명식 해석을 익명 순서로 비교한다. 예컨대 F03의 소통에서는 연간 상관과 월간 정관을 “제안”과 “합의 기준”으로 연결한다. 독자가 첫 문장의 간지를 외우지 않고 그 연결을 설명하는지 자유 응답으로 본다. 근거를 표에서 찾았는지, 자신에게 좋은 말이라 골랐는지를 나눠 기록한다.
2. **역할 쌍의 반복.** 한 후보 안에서 (위치, 천간, 십성)의 두 끝점을 정렬해 모든 LIMITED 지지 조건을 대조한다. 활동과 자원 장에서 좌우가 뒤집힌 같은 쌍을 두 독립 근거로 더하지 않는다. 월령 정확 투출은 별도의 위치 증거로 구별한다. 같은 역할명의 다른 위치는 위치가 다른 증거이며 효과의 독립성이 입증된 것은 아니다. F03의 상관–편재가 두 영역에 쓰일 때 독자는 실제로 다른 설명을 얻는지 묻는다.
3. **보류 장의 추가 가치.** 원국 후보별 4개 신규 영역과 6장 중 새 역할 해석이 직접 있는 장(3/4), 해당 장이 모두 보류인지, 원자료 위치 근거의 서로 다른 묶음 수, 반복 쌍, 전체 장별 상태를 기록한다. 1/2장은 무료 사실·구조, 5장은 해당 시간축, 6장은 앞선 해석의 종합이다. 기존 장과 요약을 추가 독립 해석으로 계산하지 않는다. 입춘 두 후보의 장별 결과는 따로 유지한다. F04처럼 두 장 모두 보류인 원국도 독자 단독 읽기에 포함한다.

원국·문장 정확성은 기존 발급 결과의 재검증 및 참조를 기준으로 한다. 전문가에게는 학파와 정책 일치, 반대 근거 누락을 묻고 독자에게는 이해·반복·근거를 설명하는 능력을 묻는다. 글자 수는 비교 자극의 길이를 통제할 때만 사용한다. 새 해석 수·위치 수·반복 수는 자동으로 “유의미한 개인화” 점수가 되지 않는다.

## 가상 자료에서 직접 확인한 한계

고정 입력 37건 중 32건에서 시간 명식을 계산했다. 입춘의 두 후보를 보존한 결과 평가할 후보는 33개, 서로 다른 팔자는 29개다. 나머지 5건은 계산 차단 사유를 보여준다. 10개 일간·12개 월지·8종 내격 구조가 들어 있다.

| 확인한 성격 | 분모 | 결과 |
|---|---:|---:|
| 행동·소통·활동·자원 각 영역의 LIMITED | 각 33후보 | 12·19·16·14건 |
| 같은 영역의 HOLD | 각 33후보 | 21·14·17·19건 |
| 3/4장에 새 역할 해석이 직접 실린 장 수 | 33후보 | 0장 2건, 1장 19건, 2장 12건 |
| 둘 이상의 영역에서 같은 위치 쌍 재사용 | 33후보 | 8건 |
| 다른 원국과 발췌문 비교 가능 | 37입력 | 26건. 다른 문구 대조 20건, 실제 같은 문구 대조 6건 |

F03에서 LIMITED 네 개는 네 독립적 효과가 아니다. 위치 증거는 월령 투출, 상관–정관, 상관–편재, 정관–편재의 네 묶음이고, **상관–편재**는 활동과 자원 설명에 함께 나온다. F04에는 월령의 정재 구조가 있어도 이 정책이 3/4장에 추가할 역할 해석이 없다. F02와 F01은 시주가 달라 겨울 목 온기 판정이 달라지지만, 활동 설명에서 위치 표기를 가리고 나면 서로 같은 문구를 실제로 사용한다. 이 세 관측은 구조적 차이·반복·공백을 보여준다. 독자가 어느 설명을 유용하게 느끼는지는 현재 자료로 답할 수 없다.

## 처분 기록 양식

각 결함에는 발견 경로(자동 검사/내부 편집/독자/전문가), 가상 사례 및 후보·claim, 자료 버전, 관찰한 문장·기대/실제, 등급·운영 조치, 원인, 수정 커밋 및 대조 사례 재검토를 남긴다. 분모가 작은 숫자는 원건수와 함께 낸다. 전문가 불일치와 독자의 구매 거절을 하나의 점수로 환산하지 않는다. 실제 평가가 없으면 독해도, 지불 의향, 만족도, 가격, 전문가 동의율은 미측정이다.
