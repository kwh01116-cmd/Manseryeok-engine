## 상태의 읽는 법

- **현재 제공 가능:** 기존 계산·분류 결과를 정확히 설명할 수 있다는 뜻이다. 과학적 예측 타당성이나 판매 준비 완료를 뜻하지 않는다.
- **제한 제공:** 명시된 정책·입력·범위에서만 판단한다. 다른 분야의 최종 결론으로 합성하지 않는다.
- **HOLD / UNSUPPORTED:** 현재 해당 개인별 해석을 제공하지 않는다. 해당 특성이 없거나 나쁘다는 판단이 아니다.
- **NEEDS_DATA / POLICY_UNRESOLVED:** 자료와 정책의 부족을 구분한다. 기존 사실을 0·부재로 바꿔 결과를 만들지 않는다.

계산 가능한 원국도 장 3·4가 미지원이고 장 5가 미요청 또는 시계 의존 보류일 수 있다. 따라서 현재 단일 상품의 **완전 제공·실결제 개방은 NO-GO**다. 제한 시제품을 검토할 수 있는 것과 구매자에게 완전한 풀이를 보장하는 것은 다르다.

## Sprint 7에 넘기는 최소 콘텐츠 묶음

1. **선택 해석 정책부터 정의한다.** 현재 확인된 구조가 어떤 제한적 해석 문장을 허용하는지, 비슷한 반례에는 왜 같은 말을 하지 않는지 고정한다. 모든 학파의 최종 강약·격국·용신 정답을 닫는 작업으로 확대하지 않는다.
2. **근거가 있는 문장만 생성한다.** 규칙 기반 또는 향후 AI 생성은 같은 claim·후보·사실·정책을 소비한다. 말투 변경으로 사실이나 판단 상태를 바꾸지 않는다.
3. **검수와 실패 처리를 먼저 연결한다.** 계산 변경·상충 문장·지원 범위 밖 판단·과장·근거 누락을 검출하고, 재생성으로 해결되지 않으면 해당 장을 보류한다.
4. **결과 저장을 설계한다.** 정책·자료 버전과 원국 후보를 재열람 시 추적하되 보관·삭제·접근통제 조건을 함께 정한다. 이번 Sprint에서는 고객 정보를 수집하거나 저장 기능을 개방하지 않는다.

실제 명리 전문가의 검토·사용자 만족 측정은 자동 테스트나 같은 모델의 재검토로 대체하지 않는다. Sprint 9의 비공개 베타 목표를 Sprint 6이나 7의 완료 실적으로 앞당겨 기록하지 않는다.
