# Sprint 9 평가 자료 계약 v0.1

`SAJU-BETA-STUDY-V01`의 수집 단위는 한 참가자가 배정된 가상 사례를 읽고 한 질문에 제출한 응답이다. 현재 레코드에는 `SYNTHETIC_INTERNAL_QA`가 붙는다. 이번 자료에서 실제 참가자 수는 항상 0명이다.

## 저장 단위

| 필드 | 의미와 발급 주체 |
|---|---|
| `studyVersion`, `consentVersion` | 서버의 질문지 버전과 동의 안내 버전. 구버전 동의를 제출하면 거절 |
| `anonymousParticipantId` | 운영자 출력 호환용 필드명. 내부 무작위 가명 식별자이며 익명성을 보장하지 않음 |
| `role`, `arm` | 운영자가 지정한 독자 BLIND·REPORT_ONLY 또는 전문가 EXPERT |
| `fixtureId` | 운영자가 배정한 가상 명식 F01–F37. 답안에는 생년월일·시각·실명 필드가 없음 |
| `reportArtifactVersion`, `materialSha256` | 실제 읽은 고정 자료의 버전과 지문. 최초 동의 후 열람에서 고정하며 달라진 자료에는 기존 응답을 연결할 수 없음 |
| `feedbackId`, `questionId`, `targetId` | 서버 발급 응답 ID, 질문지 항목, 전체·장·비교 글 자리·후보별 해석 ID |
| `value` | 해당 질문 규격에 맞춘 1~5 정수, 지정한 항목 중 하나, 또는 600자 이내 의견 |
| `submittedAt`, `consentedAt`, `completedAt` | 서버가 기록한 UTC 시각. 수정하면 해당 응답의 제출 시각이 갱신됨 |
| `blindKey`, `comparisonType` | 잠근 세 자리의 조건 배정과 비교 유형. 다른 명식에서 같은 문장이 나온 경우와 다른 문장이 나온 경우를 구분한다. 참가자에게는 완료 후 구성을 설명한다. |

내보내기에서는 역할·배정·동의·자료 버전을 응답 묶음의 부모에 한 번 기록한다. 자유 서술은 `kind=text` 질문, 문제 분류는 `issueCategory` 선택 항목이다. 질문과 선택지의 실행 기준은 [forms.mjs](../../scripts/beta/forms.mjs)에 있다.

## 제출과 완료

- 참가자는 자기 세션 쿠키와 CSRF 값을 제시한다. 요청 본문은 `questionId, targetId, value` 세 필드만 받는다. 배정·동의·자료 버전·시각은 서버가 결정한다.
- 자연 키는 가명 식별자·질문·대상의 조합이다. 같은 답을 다시 보내면 `DUPLICATE`와 같은 응답 ID를 반환한다. 잠그기 전 변경은 같은 응답 ID에서 수정한다. 서로 다른 장과 전문가의 의견은 독립 행이다.
- 블라인드 독자는 글 세 자리 각각의 구체성·개인화, 선호 또는 구별 어려움, 판단의 근거를 기록한 뒤 잠근다. 그 전에는 본문 평가를 제출할 수 없다. 비교 평가를 잠근 이후에는 앞선 답을 바꿀 수 없다. 본문 평가가 끝난 뒤에만 대조 자료의 성격을 설명한다.
- REPORT_ONLY 독자는 비교 글 없이 본문을 읽는다. 6장 이해도, 전체 이해도·개인화·구매 가치·구매 의향과 가장 유용한 장으로 완료 여부를 판정한다. 구체적 기억, 긴 장, 무료 설명과의 차이, 거절 이유와 가격 조건은 선택 응답이다.
- 전문가는 자격 유형·경험 구간·학파에 범주로 답한다. 각 항목에 응답 보류를 선택할 수 있다. 실제 claim은 후보별 여덟 관점으로 검토한다. claim이 없는 사례에는 예외 처리 검토만 제출한다. 빈 claim에 임의 ID를 만들지 않는다.
- 완료된 건도 철회할 수 있다. 철회하면 해당 참여의 세션과 활성 평가 레코드를 지운다. 열람·집계·내보내기에 다시 나타나지 않는다.

## 운영자 집계

`aggregate`는 자유 서술과 가명 ID를 표시하지 않는다. 진행 중·완료 건수를 따로 세고, 완료된 독자 평가의 분모와 장별 이해도 평균(1~5, 한 자리), 개인화, 구매 의향, 가장 유용한 장, 거절 사유 범주를 **실험군별로** 표시한다. 응답이 없으면 평균은 `null`이다. 문제 제보는 미완료 건도 포함하며 근거가 불분명한 문장은 사례·장 또는 claim으로 찾는다. 개인별 강평은 별도 보호된 내보내기에서 읽는다.

블라인드 선호와 평가 점수는 무작위 자리 순서를 복원해 A·B·C별로 집계한다. A와 C의 문장이 같은 층과 다른 층을 각각 표시한다. 참가자는 ‘구별하기 어려움’을 고를 수 있다. 전문가 REVISE/REJECT의 분모는 완료한 전문가의 최종 claim 의견 수다. 검토 기준 여덟 행을 여덟 표로 계산하지 않는다. 한 claim에 대해 의견이 갈리면 그 분포를 그대로 보존한다. 자료가 없는 사례의 평가는 별도 행이다. 이 숫자는 가상 연습 결과이며 구매 전환, 예측력, 실제 전문가 합의율로 사용할 수 없다.

## 내보내기와 삭제

운영자는 서버를 멈춘 뒤 로컬 CLI로 새 JSON 파일을 명시적으로 만들 수 있다. 파일명은 새 영숫자 이름으로 제한하며 지정한 `.private` 상태 폴더의 `operator-output`에 저장한다. 기존 파일을 덮어쓰지 않는다. 내보낸 파일에는 자유 의견이 포함된다. 파일을 소유한 운영자는 별도 사본과 수명도 관리해야 한다. 참가자 화면과 HTTP 경로에서는 내려받을 수 없다. [개인정보·보안 조건](SPRINT9_BETA_PRIVACY_SECURITY.md)
