# 가상 명식으로 준비하는 비공개 읽기 연구

2026-11-22. **SAJU-ROADMAP-V1 / 2026-11-15, Sprint 9.** 현재 사용자는 로컬 운영자와 합성 응답을 보내는 검증 도구다. 실제 참여 세션과 모집은 승인 대기다.

## 확인하려는 구매 가치

무료 화면에서 독자는 네 기둥과 분류를 볼 수 있다. 시제품은 조건이 충족된 배치 두 가지를 연결하고, 그 해석을 제한하는 근거와 자신이 생각해 볼 질문을 덧붙인다. 독자가 이 차이를 구체적인 문장으로 짚을 수 있는지, 같은 주제의 일반 설명이나 다른 명식의 해석을 보여줘도 비슷하게 느끼는지 확인한다. 정관격 성패, 용신 확정이나 실제 사건 예측을 이번 평가로 검증할 수 없다.

| 진행 단계 | 사용할 자료와 결정권 | 종료 조건 |
|---|---|---|
| A. 내부 점검 | 기존 서버용 데이터팩, 고정된 가상 출생 사례, 합성 응답만 사용 | 실제 엔진 발급 결과, 화면, 초대·철회·복구 및 판매 차단 검사를 재현 |
| B. 감독 테스트 준비 | 독자용·전문가용 안내, 질문, 비교 발췌문과 대조 키, 운영자 삭제 절차 | 모집·수집 방법, 접근자, 보존기간, 화면과 참여 설명문을 소유자가 승인 |
| C. 독립 평가 | 독자는 이해도·차별성·구매 가치를, 전문가는 원국·정책·반례를 개별 검토 | 실제 분모와 의견 불일치를 기록하고 결함 수정 후 같은 과제를 다시 검토 |

기술 점검은 C의 표본에 포함하지 않는다. 판매·출시와 실제 출생정보 수집 승인은 별도다. 실제 참가자 평가를 시작하려면 담당자·감독 환경·연락 방법·삭제 방법을 확정해야 한다. 첫 회차는 가상 사례만으로 진행하는 안을 제안한다.

## 연구 화면과 운영 경계

- 운영자가 역할과 읽을 자료를 미리 지정한다. 독자는 블라인드 발췌 비교 후 본문으로 이동하거나, 해석이 거의 없는 사례도 포함한 본문 평가에 배정된다. 전문가는 판정 보류·계산 불가 사례를 포함해 구조와 근거를 검토한다.
- 웹 화면에 출생정보 입력·원자료 내려받기·관리자 집계를 두지 않는다. 자료는 승인한 기존 팩에서 실행한 결과다. 비교문에 등장하는 두 명식은 모두 고정된 가상 사례다.
- 열람 전 안내, 동의, 응답 중간 저장, 재열람·철회, 만료·취소된 초대 거절을 제공한다. 지불 의향과 기대 가격은 선택형 연구 문항이다. 주문이나 금전 이동은 없다.
- 기존 개발 모드는 가상 결제 여정을 사용한다. 내부 연구 모드는 별도 포트·세션·저장소를 사용한다. 실제 비공개 베타와 운영 모드는 서버 시작 단계에서 거절한다.

## 진행자가 처리할 모의 문의

| 분류 | 먼저 확인할 내용 | 처리와 기록 |
|---|---|---|
| 날짜·시각 입력 오류 | 날짜 형식, 달력 종류, 윤달 입력 | 기존 입력 검증 메시지를 확인하고 개인정보 없이 오류 종류만 기록 |
| 화면마다 다른 결과 | 일주 교체 정책, 달력·시계 프로필, 원국 후보 | 동일 입력과 정책으로 재현한 뒤 계산 차이와 정책 차이를 구분 |
| 출생 시각 미상 | 제공 가능한 장과 필요 정보 | 정오 등 임의 시각을 입력하지 않고 보류 사유 제시 |
| DST·절입 표시 분 | 사라진 시각·중복 시각·두 원국의 구별 | 허용된 후보를 표시하고 추가 정보의 필요성 안내 |
| 해석 품질 불만 | 사례·장·문장과 해당 판단의 근거 | 문제 신고로 접수해 P0–P2 분류. 반복·보류 사례도 포함 |
| 결제·환불 | 모의 거래인지, 환불·접근 상태 | 실판매 차단 안내, 모의 승인 중복과 환불 뒤 열람 거절 확인 |
| 재열람 장애 | 초대 만료, 권한 철회, 자료 버전, 저장 무결성 | 운영자가 자신의 합성 자료로 재현. 다른 사용자의 리포트로 대체하지 않음 |
| 삭제 요청 | 해당 참여자의 활성 응답·운영자 사본 | 철회 후 읽기 거절 및 집계 제외 확인. 내보낸 사본은 별도 확인 |
