# 명리 전문가 독립 검토 지침 · v0.1

**평가 질문**은 이 문장이 이 원국, 원전·주석 및 표시된 프로젝트 선택 규칙에 맞는지다. 검토 단위는 **가상 입력 안의 원국 후보 한 개에 속한 claim 한 개**다. 행동·소통·활동·자원 네 영역의 보류 문장도 검토한다. 원국을 만들 수 없는 입력에는 claim 번호가 없다. 이때 입력 차단 사유와 화면 설명을 별도 문제로 신고한다.

## 표본과 독립성

Sprint 7에서 해석 실행 전에 고정한 가상 입력 37개를 순서대로 F01–F37에 대응시킨다. 참가자의 생년월일을 쓰지 않는다. 모든 허용·경쟁·보류·예외를 기술 자료에 포함하고 수행 시점에 기존 기대 계약과 대조한다. 근거는 실제 엔진이 생성한 S7 리포트다. 같은 날의 정책·경계 반복은 독립된 사람이나 새로운 강약 사례로 세지 않는다.

| 우선 비교 | 확인할 오류 |
|---|---|
| F01 ↔ F02, 같은 일주·다른 시주 | 겨울 목 온기 후보를 최종 용신으로 해석하거나, 두 시주의 M5 결론을 합치는지 |
| F03 ↔ F04 | 월령 정관의 정확 투출과 정재의 비투출을 구별하는지. 재물 관점 HOLD가 가난·재물 부재가 되는지 |
| F05, F36, F37 | 입춘 전후 후보에 같은 연·월주나 다른 후보의 claim이 들어가는지 |
| F06, F34, F35 | 토왕 계절 대안이 원국을 두 사람으로 만들거나 같은 근거를 중복시키는지 |
| F07 ↔ F08 | 없는 시각과 두 번 있는 시각의 차단 사유. 명식·claim이 없어야 함 |
| F24–F32 | 비겁 본기, 기타 장간 투출, 경쟁, 午 장간 호환 보류 및 서로 다른 계절 맥락 |

독립적인 명리 전문가 **3명 이상**을 목표로 한다. 모집·동의 승인 뒤 운영자는 같은 사례를 서로 다른 전문가에게 배분한다. 첫 회에는 F03, F04를 공통 앵커로 삼고 나머지 시간을 서로 다른 계절과 적용 조건에 배분한다. 처음부터 기관·학파 합의를 전제로 하지 않는다. 자격의 종류·대략적 상담/연구 경력 구간·주로 따르는 관점만 선택적으로 기록한다. 실명·연락처·자격증 사본·내담 기록 수집은 범위 밖이다. 검토자의 신원·자격 검증은 아직 수행하지 않았다.

## 실제 시행 절차

1. 예상 45–60분을 한 회차의 계획값으로 안내한다. 정확한 소요시간은 첫 승인된 파일럿에서 잰다. 초대와 동의 후 해당 가상 사례를 연다. 여러 사례를 나눠 볼 때는 같은 전문가의 반복을 독립 전문가 수에 더하지 않는다.
2. 먼저 원국·발표 분·시계 정책·후보와 실제 지지/천간 위치를 확인한다. claim에 붙은 원본 식별자, 위치, 적용·경쟁 조건, 원전/주석/프로젝트 출처, 보류 범위를 함께 읽는다.
3. **① 계산과 일치 ② 문헌 또는 선택 정책과 일치 ③ 적용 전제 충족 ④ 반대 근거 보존 ⑤ 단정의 정도 ⑥ 학파 의존성 ⑦ 추가된 독립 정보 ⑧ 유지·수정·삭제·보류 의견**을 구별한다. 평가는 원국과 문장 양쪽을 인용할 수 있어야 한다. 해석의 출처와 프로젝트가 확장한 표현은 서로 다른 열로 본다.
4. 결론은 `ACCEPT`, `ACCEPT_WITH_QUALIFICATION`, `REVISE`, `REJECT`, `SCHOOL_DEPENDENT`, `INSUFFICIENT_EVIDENCE` 중 고른다. 남길 제한, 빠진 조건, 다른 학파의 해석 또는 비교 문장을 함께 기록한다. 모르면 근거 불충분으로 남긴다.
5. 첫 평가는 각자 독립적으로 수행한다. 다른 전문가의 의견이나 개발팀의 기대 답을 먼저 보여주지 않는다. 두 입장이 다르면 동일 fixture·후보·claim별 양쪽 판단을 보존한다. 계산 오류는 재현 자료로, 규칙 구현 오류는 버전과 코드로, 학파 차이는 각 전제와 출처로 확인한다. 다수결로 원 판단을 교체하지 않는다.
6. 수정 후 같은 고정 사례와 반대 결과 사례를 다시 계산한다. 문장 또는 정책이 바뀌면 새 버전으로 최초 평가와 나란히 기록한다. 미해결 고위험 항목은 해당 제공을 중지한다.

### 승인 후에만 사용할 의뢰문 초안

“가상 사례의 사주 리포트를 읽고, 지정한 원국과 근거가 실제 설명에 맞는지 검토해 주세요. 동의하지 않는 해석은 따르는 학파와 필요한 전제를 알려 주시면 됩니다. 점수를 맞힐 필요는 없습니다. 실제 상담 자료나 개인의 출생정보는 보내지 마세요. 참여와 중단은 자유이며 제공된 자료는 외부에 공유하지 않습니다.”

명리 전문가의 읽기나 학파 간 합의는 아직 없었다. 향후 이 평가가 확인하는 것은 설명의 정합성과 이견이며 현실 사건의 예측력은 평가 대상에 포함하지 않는다.
