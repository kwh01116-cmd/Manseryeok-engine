## 공통 입력·의미·제외 조건

표면 대상은 **일간을 제외한 연·월·시 천간**이다. 각 위치의 기존 M2 십성을 소비한다. 장간만의 존재를 표면 투출로 승격하지 않는다. 정확 투출은 M4의 동일 천간 문자·위치 연결이며 동오행의 다른 음양은 대신하지 못한다. 월령 기타 장간과 비겁 경쟁은 기존 결과에 있는 그대로 보존한다. 원국 부모가 둘이면 각각 검사하고, 계절 대안 둘은 같은 부모의 관점에 추가 원국을 만들지 않는다.

**해석 선택 대상과 관계 문맥의 범위는 다르다.** 네 영역의 역할 선택·쌍은 위의 세 위치만 사용한다. 반면 실제 표면 천간의 오합 짝 문맥은 일간을 포함한 원국 네 위치에서 수집한다. 일간의 기존 M2 십성은 `null`로 보존하며, 일간을 별도 비겁 지원이나 새 해석 쌍의 대상으로 추가하지 않는다. 일간 참여 합과 타간 사이의 합을 구별하고, 어느 쪽도 합거·합화·역할 소실·실제 간섭으로 확정하지 않는다. 이 구분은 후속 검토에서 발견한 문맥 보존 누락의 보완이며 아래 네 영역의 선택 전제·상태를 바꾸는 새 효력 규칙이 아니다.

상태는 실제 Report 상태와 분리해 읽는다. 적용한 해석 관점은 `LIMITED`, 미충족/범위 밖/미정은 `HOLD`다. 행동 정책이 적용되고 월령의 경쟁 투출도 있으면 `LIMITED_COMPETING`이라는 적용 사유로 대안들을 병치하되 claim 상태는 `LIMITED`다. 다른 영역은 해당 쌍의 전제를 따로 검사하고 월령 경쟁도 삭제하지 않는다. 이것은 새 강약·격 선정 상태가 아니다. 필요한 사실/정책/출처가 없거나 다른 후보에서 왔다면 정상 HOLD로 숨기지 않고 입력/참조 오류를 반환한다. 고전·프로젝트 해석의 효과가 미정이라는 것과 입력 오류를 구별한다.

기존 근·인성 결정이 이번 입력에 없으면 새로 평가했다고 표시하지 않는다. `NO_HOLD`를 실제 생조 유효로, 인성 합 채택 유보를 원국에서 인성 삭제로 바꾸지 않는다. 공통 한계는 한 번 정리하고 각 claim에는 실제 중요한 경쟁 조건·미평가 전제만 연결한다.

## 수락·검증·남는 한계

네 정책은 원문에 있는 역할의 비유와 **프로젝트가 정한 적용 조건**을 결합한 제한적 선택 정책이다. 따라서 적용 결과도 원칙적으로 LIMITED이며 객관적 성격 진단의 SUPPORTED로 표시하지 않는다. 어떤 영역에 HOLD가 많아도 채택 기준을 낮춰 비율을 맞추지 않는다. 단순 긍정어·대부분의 사람에게 맞는 형용사·생년월일 치환을 개인화 성과로 세지 않는다.

기능 수락은 정책/후보/근거 연결·긍정/반례/HOLD·동일 입력 재현·실패시 안전 보류를 검사하는 것이다. 한국어 전문의 별도 AI 읽기 검토는 인간 전문가·독립 학파 검증이 아니다. 사용자 이해·자기 성찰 가치·구매 가치, 실제 성격/예측 타당성, 법률·유료 출시 수락은 미검증이며 고정 로드맵의 별도 게이트로 남긴다.
