# 첫 리포트 사업·운영 준비 체크리스트

2026-11-21. 이 문서는 검증이 필요한 가설과 출시 전 질문을 정리한다. 법률 의견, PG 사용 가능 확인, 사업자 신청·기관 연락·실결제·고객 모집·운영 정책 확정 기록이 아니다. [단일 상품 PRD](SPRINT6_SINGLE_REPORT_PRD.md)와 [고정 로드맵](SAJU_ROADMAP_LOCKED_V1_20261115.md)의 Sprint 8~10을 대체하지 않는다.

## 기존 근거와 한계

확인한 기존 자료는 [Sprint 2 기능 비교](../research/SPRINT2_PRODUCT_FEATURE_MATRIX_20261114.md#공식-공개-표면), [Sprint 3 기능 행렬](../research/SPRINT3_PRODUCT_FEATURE_MATRIX_20261114.md), [스토리 UX 설계](../PRODUCT_STORYTELLING_UX_ROADMAP.md)다. 공식 스토어 기능 설명을 읽은 기록이지 경쟁 유료 리포트의 전문·계산 정확도·환불·구매 전환을 감사한 자료가 아니다. 별도 실구매 벤치마크나 독립 사업 전략서는 이번 저장소 조사에서 확인하지 못했다.

이번 작업에서는 새로운 가격·시장 규모·경쟁 순위를 조사하거나 확정하지 않았다. 기존 문서의 기능·지원 연도·권리 상태는 당시 기록으로 읽고, 현재 범위는 [지원 행렬](../research/EXTENDED_YEAR_SUPPORT_MATRIX.md)과 서버 자료 계약을 따른다.

## 기존 API 자료 권리의 재사용 범위

[KASI 이용권 감사](../research/KASI_DATA_RIGHTS_DISTRIBUTION_AUDIT_V01.md)와 [API-only 팩 계약](../contracts/SERVER_API_ONLY_DATA_PACK_V01.md)은 두 허용 API에서 실제로 유래한 자료의 서버 내부 사용을 `VERIFIED_ALLOWED_WITH_CONDITIONS`로 구분한다. 이는 현재 팩의 원문·행·출처·고지와 선언한 사용 조건을 유지하는 범위다. 고객 파일 재배포는 `UNRESOLVED`다.

이 수락을 KASA 공고·웹 달력·TXT·OSS 내장표·고전 전사·스캔·이미지 등 모든 결합 자료의 허락으로 확대하지 않는다. 데이터 수치의 이용허락, 외부 코드 라이선스, 문헌 표현의 이용권, 서비스 전체의 공개 출시 조건은 서로 다른 확인 대상이다. 이번 Sprint는 새 API 수집·키 사용·기관 질의·새 조건 동의를 하지 않는다.

## 검증 단계의 분리

- **Sprint 6:** 가상 입력·코드·보고서와 적격성 시제품 검토. 자동 검사와 AI 읽기 대조의 한계를 기록한다.
- **Sprint 7:** 지원 해석 정책·생성·근거 추적·검수·안전한 실패·저장 설계. 사용자에게 없는 판단을 생성하지 않는다.
- **Sprint 8:** 구매부터 재열람·실패 복구·환불 상태까지 제품 흐름을 구현한다.
- **Sprint 9:** 비공개 베타에서 실제 사용자·명리 전문가의 표본 검토와 운영 지표를 확인한다.
- **Sprint 10:** 법률·사업·데이터 권리·결제·운영 조건을 검토한 뒤 제한적 판매를 별도 수락한다.

이 순서와 핵심 수락 조건은 고정 로드맵을 따른다. 대안을 제안할 때는 CHANGE_PROPOSAL로 남기고 사용자 승인 없이 목표나 공개 출시 조건을 바꾸지 않는다.
