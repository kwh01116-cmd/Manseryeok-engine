# 첫 번째 단일 사주 리포트 PRD v0.1

작성일 2026-11-21. 가칭은 **나의 사주 해석 리포트**다. 이 문서는 [SAJU-ROADMAP-V1](SAJU_ROADMAP_LOCKED_V1_20261115.md)의 Sprint 6 제품 설계 기준이며, 공개 판매·가격·효력의 승인 문서가 아니다. 실제 구현·출력·검증 결과는 Sprint 6 실행 기록과 구분한다.

## 먼저 해결해야 할 제품 문제

현재 엔진은 명식과 여러 구조를 계산하지만, 그 결과를 모아 놓았다는 사실만으로 개인별 유료 풀이가 되지는 않는다. 특히 성향·관계·직업·재물에 관한 실행 정책이 없다. 이 네 주제를 익숙한 일반 문장으로 채우면 근거가 없는 개인화가 된다. 반대로 모든 장을 기술적 제한 설명으로만 채우면 무료 만세력보다 더 읽을 가치가 있는지 확인하기 어렵다.

이번 시제품의 검증 대상은 **서로 다른 근거를 연결해, 독자가 자신의 명식에서 무엇이 확인됐고 무엇이 달라질 수 있는지 이해하게 만드는 가치**다. 구매 의사·가격 수용도·고객 만족은 아직 검증하지 않았다. 완전한 개인별 유료 리포트 제공은 현재 **NO-GO**다. 실행 가능한 시제품의 기술 수락과 상품성 판정은 따로 남긴다.

## 고객과 사용 목적 — 가설

목표 고객은 한국어로 사주 원국을 확인해 본 적은 있지만 십성·월령·통근 같은 항목을 서로 어떻게 읽는지 어려워하는 사람이다. 전통 명리를 자기 이해와 성찰의 관점에서 읽으려는 수요를 가정한다. 이 고객군의 실제 규모나 지불 의사는 조사하지 않았다.

고객 문제 가설은 세 가지다.

- 여러 앱의 용어나 결과가 달라도 무엇이 계산 차이이고 무엇이 선택 규칙 차이인지 알기 어렵다.
- 정관·공망·왕·사 같은 단어를 성격이나 사건의 확정적 예언으로 오해하기 쉽다.
- 출생 시각·절입 경계·해석 정책 때문에 결과가 달라져도 한 가지 단정만 받으면 차이의 이유를 검토하기 어렵다.

따라서 첫 제품은 정답이나 미래 사건을 보장하지 않고, **내 입력에 따른 핵심 구조·반대 근거·보류 이유를 같은 문맥에서 읽는 리포트**를 목표로 한다. 이것이 실제 구매 가치가 있는지는 Sprint 9의 사용자·전문가 검토에서 확인한다.

| 유료 본문 후보 | 월령·격 구조·계절·근·제한된 도움 요소 후보를 연결한 설명, 비교 가능한 반대 근거, 시간축과 경계, 종합·성찰 질문 | 같은 자료를 길게 반복하는 것을 부가 가치로 세지 않는다. 근거가 없는 성향·주제별 판단은 제공하지 않는다 |

무료 만세력과의 차별점은 계산 항목 수보다 **근거 사이의 연결과 읽는 순서**라는 가설이다. 계산식이나 원데이터를 독점한다고 주장하지 않는다. 유료 전환이나 적정 가격은 이번 문서에서 추정하지 않는다.

제한적인 M5는 겨울 甲·乙 일간의 亥·子월 온기 검토만 소비한다. 화가 관측되지 않을 때의 후보와 화가 이미 있으나 충분성을 모르는 HOLD를 구분한다. 이를 화의 실제 부족량·최종 용신·색상·행동 처방으로 번역하지 않는다.

## 읽는 경험과 근거 모델

첫 문단은 날짜와 간지의 나열보다 **이 명식에서 실제로 선택한 핵심 연결**을 먼저 말한다. 예를 들어 같은 일주여도 시주에 포함된 화의 유무가 한정 M5 후보와 HOLD를 가르는 경우, 그 차이를 설명한다. 정관격 후보에서는 월령과 투출이 연결되는 이유를 설명하되 실제 격 성립이나 성격을 붙이지 않는다.

문장은 계산 사실·전통 분류·선택 정책 판단·이를 풀어 쓰는 서술로 분리한다. 후보 ID·정책 버전·factRefs 등은 상세 근거에 남기고 기본 본문에서는 사람이 이해할 용어를 사용한다. HOLD·NEEDS_DATA·POLICY_UNRESOLVED를 빈 문장이나 부정적인 평가로 바꾸지 않는다.

일반 보고서와 향후 캐릭터 대화는 같은 근거·주장 ID를 소비한다. 말투를 바꿔도 새로운 성격·사건·효력을 추가할 수 없다. 이번에는 캐릭터 UI·이미지·애니메이션·LLM을 구현하지 않는다. 세부 데이터·문장 계약은 [리포트 스키마](REPORT_SCHEMA_V01.md), [근거 기반 문장 계약](REPORT_CLAIM_CONTRACT_V01.md)에 둔다.

## 제공 적격성과 판매 게이트

계산 가능 여부와 전체 상품 제공 여부를 따로 판단한다. 적격성은 **완전 제공 가능 / 제한 제공 가능 / 추가 정보 필요 / 제공 불가능**을 구분하며, 각 장의 상태와 이유를 포함해야 한다.

- 시각 미상·미선택 DST 반복 시각은 추가 정보가 필요하다. 없는 시각에 원국을 만들어 제공하지 않는다.
- 절입의 두 원국은 둘 다 보존한다. 첫 후보만 골라 전체 제공 가능으로 바꾸지 않는다.
- 한 원국 아래 계절 대안 둘은 새 고객 두 명이나 새 원국 두 개가 아니다.
- 대운 입력이 없으면 그 기능을 미요청/추가 입력 필요로 구분한다. 성별을 추정하지 않는다.
- 2027 양력 명식 일부 지원은 2027 음력·전체 월운·전체 해석 지원을 뜻하지 않는다.
- 성향·주제별 정책이 없는 현재 상품은 계산에 성공해도 완전 제공을 보장하지 않는다. **실결제 가능 또는 공개 판매 가능이라는 상태를 반환하지 않는다.**

범위의 기준은 [현재 연도 지원 행렬](../research/EXTENDED_YEAR_SUPPORT_MATRIX.md)과 서버 계약이며, 로드맵의 Sprint 5.1 수집 승인이 없으면 새 자료를 호출하지 않는다.

## 기존 조사와 아직 검증하지 않은 사업 가설

저장소에서 확인한 비교 자료는 [Sprint 2 공식 제품 표면](../research/SPRINT2_PRODUCT_FEATURE_MATRIX_20261114.md#공식-공개-표면), [Sprint 3 기능 행렬](../research/SPRINT3_PRODUCT_FEATURE_MATRIX_20261114.md), [기존 스토리 UX 설계](../PRODUCT_STORYTELLING_UX_ROADMAP.md)다. 앞의 두 문서는 2026-11-14의 공식 개발자 설명과 우리 실행 기능을 비교했으며, 경쟁 유료 리포트의 품질·가격 수용도·계산 정책을 검증한 자료가 아니다. 스토리 UX 문서도 설계 가설과 과거 상태를 포함한다.

이번 문서 작업에서는 별도의 최신 유료 리포트 구매 비교·사용자 인터뷰·가격 실험·독립 사업 전략서를 확인하지 못했다. 과거 문서의 지원 연도·권리·작업 순서는 현재 고정 로드맵과 지원 행렬을 덮어쓰지 않는다. 운영 준비의 미확정 사항은 [사업·운영 체크리스트](SPRINT6_BUSINESS_READINESS.md)에 분리한다.
