# ENGINE-PARITY-TRACK-V1 · E1 실제 입력 대조

## 결과를 보기 전에 고정한 표본과 분모

- 기준 표본은 현대 한국 표준시, 양력, 자정 일주 교체, 선택 일주 기준 시간으로 계산한 가상 입력 240건이다. [입력 목록](../../test/fixtures/e1-240-births-v1.txt)은 날짜·시각, 일간+월지, 근·표면 지원 배치만 담는다. 대상이 E1 결과를 내는지, 점수가 어느 쪽인지로 사례를 고르지 않는다.
- [선정기](../../scripts/engine/select-e1-cohort.mjs)는 기존 M1 원국과 M2 장간·생극 표만 읽는다. 각 양력 월 10~19일을 순서대로 둘러본다. 날짜가 속한 연도는 월마다 1990년에서 2년씩 증가시키고, 다음 표본을 찾을 때 연도를 한 해씩 이동한다. 실제 M1의 일간·월지 조합이 같되 네 지지의 일간 근과 세 표면 천간의 비겁·인성 위치 표시가 다른 첫 두 사례를 고른다. 월지 표기를 달력 월에서 추정하지 않는다. 표시는 지지 순서 연·월·일·시의 정확근 E, 다른 동오행근 S, 없음 -, 이어서 연·월·시간의 비겁 P, 인성 R, 기타 -다. 같은 육십갑자의 시간만 바꿔 같은 근거를 반복하지 않도록 두 사례의 날짜와 배치를 검사한다.
- 120칸마다 2건을 담은 층화 표본이다. 전국 출생 분포나 임의 추출 표본의 비율로 일반화할 수 없다. 분모는 요청 수·후보 수·유일한 원국·특수 검토 제외 일반 원국을 구분한다. M3의 방향 등급(신강/신약)과 경계 등급은 따로 센다. M5의 동순위·단독·보류를 구분하고, 일반 원국에는 중간 경계로 보류한 경우도 포함한다. 기준은 실행 이전에 고정한 [M3 정책](../research/M3_PRODUCT_STRENGTH_POLICY_V01.md)과 [M5 정책](../research/M5_EOKBU_CANDIDATE_POLICY_V01.md)을 따른다.
- 비교 대상은 과거 고정 100건 가운데 현대 출생 범위의 90개 입력, 공급한 네 기둥을 그대로 받아 수행한 korean_saju 97개 후보와 ssaju의 출생 입력별 기록이다. 과거 실행 영수증과 원 출력 지문을 먼저 대조하고 E1 후보를 원 입력 ID와 실제 네 기둥으로 연결한다. 10개의 옛 역사시 입력은 그때의 명식 기준이 없으므로 이 비교 분모에서 뺀다. 현재 역사시 검증은 별도 경계 묶음에 남긴다. 직접 실행했던 원본 결과의 재분석이며 새 서비스 호출이 아니다. [기존 OSS 실행 기록](OSS_ENGINE_COMPARISON_EXECUTION_20261114.md)
- 두 문헌 예시는 『子平真詮評注』에서 인용한 四辛卯·四丙申의 **무근 및 표면 비겁만으로 강을 단정할 수 없다는 조건**만 독립적으로 기대한다. 양력 생일을 부여하지 않는다. [기존 원문·주석 대조](../research/M3_LIMITED_SYNTHESIS_POLICY_V01.md)
- 정해의 공식 공개 그림 한 장에서 네 기둥과 표시 결과를 대응시킨다. 출생일·시각·비공개 수치식을 추정하지 않는다. 그림의 표시는 순서대로 甲午·己巳·丁卯·庚子, 득령·득지·득세, 신강한 편 69, 관성→식상→재성이다. 원 그림은 패키지에 넣지 않는다. [정해 공식 억부 예시](https://doc.8-codes.com/origin/ukboo.jpg)
- 외부 강약의 중화와 E1의 판정 경계는 같은 결론이 아니다. 강/강과 약/약만 방향 일치, 반대 방향은 정책 차이, 하나라도 경계면 비교 제한으로 기록한다. 억부 단독 목적과 외부 조후·전왕 우선은 비교 불가로 분리한다. 같은 이름·숫자를 반환해도 같은 정책의 해석 정확도를 확인했다고 보지 않는다.
