## 개발 중 발견 및 수정

1. 실제 역사시 원국은 월운을 생략하면 기존 DTO에 NOT_REQUESTED만 기록한다. 초기 E2가 결과 안의 정책 메타데이터를 필수로 읽어 정상 원국 두 건이 실패했다. 해당 시계 프로필의 월운 정책을 표시하고 미요청과 역사시 정책 미채택을 분리한 뒤 재실행했다.
2. 후보별 세운의 출생 전 조회 표지, 성별·개수가 빠진 대운의 원래 입력 참조를 검수에서 보완했다. 지장간의 원국 배분은 분모 10,000단위·정책 버전을 함께 기록한다. 누락 입력을 바꾸지 않고 세운 등 독립 요청은 실행한다.
3. 초기 패키지 조립 시 필수 격국 정책 문서가 아직 없어 빌드가 중단됐다. 문서를 완성하고 새 디렉터리에서 조립했다. 첫 로컬 커밋 시도는 Git 작성자 미설정으로 실패했다. 기존 작성자 정보를 해당 커밋에만 지정했다.
4. 첫 전체 검사는 1,160/1,162였다. 기존 v2 패키지를 두 번 빌드하는 동안 후속 문서가 작업 트리에 추가돼 manifest의 `workingTreeStatusSha256`이 달라졌다. 어긋난 필드는 이 지문 하나였고, Node가 실패한 하위 검사와 이를 포함한 상위 검사를 각각 1건으로 집계했다. 같은 코드·기대값에서 편집을 멈춘 뒤 해당 검사 파일은 7/7 통과했다. 첫 실패 로그는 `.private/engine-e2-20261122/qa-f80ed44-final-check.log`에 보존했다.

## 독립 실행 방법

아래 명령은 저장소 루트에서 시작한다. `node`는 Node 22다. 계산에는 생성된 엔진 디렉터리와 별도 보관한 서버 자료팩만 필요하다. 실제 이름과 다른 위치로 복원한 경우 앞의 두 경로만 바꾼다.

```powershell
$engine = (Resolve-Path '..\.private\engine-e2-f80ed44\engine').Path
$data = (Resolve-Path '..\.private\engine-e2-f80ed44\server-data').Path
$pin = 'eaefebd8026c9d048b89561a12fb7f31e3ebfea19ae743c2aeabf81860df6367'
$request = Join-Path $engine 'docs/contracts/examples/engine-e2-request-v1.json'
[Console]::OutputEncoding = New-Object System.Text.UTF8Encoding($false)
$report = & node (Join-Path $engine 'engine.mjs') run --manifest-sha $pin --data-pack $data --request $request | ConvertFrom-Json
$report.candidates[0].features.psobject.Properties | ForEach-Object { [pscustomobject]@{ Feature = $_.Name; State = $_.Value.availability } } | Format-Table -AutoSize
$report.candidates[0].features.sinsal.result.observations | Format-Table name, basis, status -AutoSize
```
