### 실제 S/T/B와 12일 대체 반례

실제 API 후보에서2026 辰월의 S는 청명 **2026-04-05 03:40**, T는 입하 **2026-05-05 20:49**다. 새 경계 B는 **2026-04-17 20:49**로 계산됐다. `S+12일=2026-04-17 03:40`과는 **17시간9분** 다르다. 이번 구현은 T에서18일을 빼며 S부터12일·30일 비례 보정으로 대체하지 않는다. 순수 정책 테스트의 합성 丙 일간과 실제 B 날짜의 辛 일간을 구분했다.

2026 입춘 전 후보의 S는 소한2026-01-05 17:23, T는 입춘2026-02-04 05:02, B는2026-01-17 05:02다. T와 같은 표시 분의 전 후보는 토왕이며 후 후보는 기존 M1이 발급한 寅월 봄이다. B에서는 parent 아래 계절 대안만 두고, T에서는 기존 M1 전/후 조건을 재사용하여 중복 분기나 Cartesian product를 만들지 않는다.

천리명고는 사립 전18일과 다섯 구간 오행 상태를 직접 확인하는 근거다. 그 책의 辛 문단은 四位前, 다른 천간과 月建篇은 四立前으로 표시한다. 이를 숨기거나 스캔 교감을 수행했다고 주장하지 않았다. 삼명통회의 청명 뒤12일·여러 장간 용사 배열·그 논의를 사립 전18일과 같은 알고리즘으로 합치지 않았다. 오행대의는 같은 상태 배열을 대조하지만 토왕 시점은 六月로 제시하므로 이번18일 타이밍의 근거로 쓰지 않았다. 王/旺의 글자 형태 차이도 기록했다.
