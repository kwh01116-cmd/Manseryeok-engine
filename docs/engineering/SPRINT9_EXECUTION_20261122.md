- 최종 UTC 실행에서 자료 적재 6452ms. 실제 원국을 제공한 32건의 생성 및 발급 검증 지연 중앙값 869.1ms, 95백분위 3253.3ms. CPU 평균 1243.2ms. 기대한 상태 37/37, QA 차단 0건, 재생성 0건. 보류 설명만 제공된 입력을 원국 생성 성공 건수에 포함하지 않았다.

- 실제 S8 가상 주문 1건에서 같은 주문 생성 요청 1회와 승인 이벤트 1회를 재전송했다. 리포트 1개, 재생성 0회, 저장 실패 0/1, 성공한 열람 2/2. 환불 뒤 읽기 거절과 리포트 디렉터리의 파일 크기 합 0바이트를 확인했다. 모의 문의 8종의 대응은 PRD에 있다. 콘텐츠 불만·근거 불명 신고는 내부 폼으로 접수·삭제했다.
- 이 주문을 생성하고 두 번 읽기까지 2.24초, 같은 프로세스 CPU 2.265초, 저장 사용량 증분 195,748바이트였다. 이 CPU 값에는 루프백 요청 측 처리도 포함된다. CPU 시간당 가정 단가가 100원이라면 단순 CPU 항목은 약 0.063원/건이다. 실제 호스팅 청구액이 아니며 유휴 시간, 메모리, 보안, 백업, 사람의 운영 비용은 따로 산정해야 한다. PG·외부 LLM 미사용, 가격·수수료·실구매 비용 미측정.
- 베타 HTTP 서버 누적 처리 시간 3607ms / 96건. 이 시간은 여러 요청을 더한 값이며 한 독자의 독서 시간과 다르다. 저장 용량과 지연은 이 컴퓨터에서 이 자료로 측정했다.
