# 2027 API 경계 보충 실행 기록 — 2026-11-11

## 현재 관측과 제한

기반 HEAD는 `00379e9143c36cc8a693166d9caaca182e64740a`다. 이 기록 시점의 A 변경은 미커밋 작업이며 아직 Push하지 않았다. 최종 전체 검사·테스트 SHA·원격 전달은 상위 통합 실행 기록에서 별도로 확인한다.

승인된 프로젝트 캐시의 페이지 1,001개와 probe 4개를 먼저 검사했으나 2027년 실제 API 응답 기록은 없었다. 기존 2027 fixture는 API 캐시로 사용하지 않았다. 인증 자료는 지정된 한 파일 안에서만 구조를 확인했고 값·행·인증 URL을 출력하지 않았다. 최초 넓은 토큰 검사에서 두 후보처럼 보였으나 하나는 인증값이 없는 URL 부분이었다. URL을 제외한 단일 평문 값만 안전하게 주입했다. 다른 폴더·계정·키 저장소를 탐색하지 않았다.

실제 2027년 연간 `get24DivisionsInfo` 요청 **1회**를 시도했으며 `NETWORK_ERROR`로 종료했다. 재시도는 0회, HTTP 응답·원문·정규화 실제 보충은 확보하지 못했다. 첫 시도 ledger와 실패 기록은 별도 비공개 디렉터리에 보존했다. 한 번의 좁은 권한 상승 재시도는 자동 승인 검토가 프로세스 실행 전에 거절했다. 거절 사유는 신뢰된 사용자 메시지에 지정 인증 파일과 해당 재시도에 대한 명시 승인이 없다는 것이었다. 거절된 실행은 API 시도 수에 더하지 않았다. 승인 없는 다른 실행 경로로 우회하지 않는다. 추가 실제 시도의 승인·결과는 후속 기록과 분리한다.

## 구현과 집중 검사

`boundary-supplement.mjs`는 독립 기대 지문·기본 후보 지문을 요구하고 실제 원문 파일과 receipt를 읽어 다시 정규화한다. 소한·입춘 두 행, 정확한 연도·operation·query·서비스·응답 지문·원문 경로를 검사한다. 전체 연간 원문 검증기는 그대로 유지한다. 런타임에는 소한만 M7 타임라인에 추가하고 입춘은 자료 준비 상태로 남긴다. 기본 M1의 완전 연도 계약과 시각 해석 범위를 변경하지 않았다.

`collect-2027-boundary.mjs`는 기존 Client·transport·parser·rate limit을 재사용한다. 작업 범위는 서비스 15012690·2027년·해당 operation·XML·연간 조회로 고정한다. 실제 전송 전 계수, 최대 10회, 페이지별 재시도 0, 안전한 ledger, 키 반사 거부, 별도 새 디렉터리의 배타 쓰기를 적용했다. 성공 원문은 정규화 완료 전에도 보존한다. 새 핀은 독립 검토 전 `PENDING_INDEPENDENT_PIN_ACCEPTANCE`다.

새 공개 합성 테스트 9개는 PASS했다. 그중 실제 subprocess 6회는 네트워크를 차단하고 키 환경을 제거한 상태에서 기존 CLI·선택 CLI·v0.2·UTC/Asia-Seoul·잘못된 핀·파일 없음 처리를 확인했다. 실제 API 원문이나 개인 출생정보를 공개 테스트에 넣지 않았다. 앞선 새 8개+기존 M7 집중 17개도 25/25 PASS했다. 이 기록은 작업 트리의 집중 검사이며 최종 전체 검사로 대신하지 않는다.

## 기존 부족 코호트의 실제 재집계

실제 a 후보를 기존 고정 manifest로 읽고 47,975 입력 벡터 전체를 검사했다. 마지막 확보 절입은 `2026-12-07T11:53` 대설이었다. 그 시각 이후 81개 벡터만 제품 경로로 계산해 양력/음력×전통 성별 두 값의 **324회 제품 호출 = 324회 출생 M1**을 확인했다. 후보는 340개였고 기산 상태는 **NEEDS_DATA 162, OK 162, AMBIGUOUS 16**이었다. 부족 162개는 모두 2027 소한의 `DA_YUN_START` 결손이다. 기존 162라는 수치를 결과에 복사한 것이 아니라 다시 세고 기대 수와 대조했다.

원본·후보 a/b의 독립 tree 지문과 원본 export 지문은 전후 동일했다. 이 검사의 API 요청은 0회다. 결과는 `.private/kasi-2027-baseline-cohort-00379e9-utc-20261111/report.json`에 비공개로 보존했다. 실행 기준은 HEAD+미커밋 변경 목록이며 최종 코드 SHA 검사는 후속 통합 단계에서 실행한다. 선택한 실제 보충은 없으므로 **실제 보충 선택·해결 건수 검사는 NOT_RUN**이다. 합성 자료에서 해결된 결과를 실제 162개 해결로 보고하지 않는다.
