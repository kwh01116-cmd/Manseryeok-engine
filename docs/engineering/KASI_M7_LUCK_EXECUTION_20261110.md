# M7 대운·세운 v0.1 — 실제 실행 기록

작업 기간: 2026-11-10~11 KST. 아래 출생 형식은 모두 개인 기록이 아닌 명시적 가상 입력이다.

## 실제 사용 결과

양력 **2026-06-01 12:00** = 음력 **2026년 4월 16일 평달 12:00**, 원국은 **丙午 / 癸巳 / 丙午 / 甲午**다. `CIVIL_MIDNIGHT`, `SELECTED_DAY_PILLAR`, `KR_API_PUBLISHED_KST_MODERN_1988_POST_DST_V1`과 `M7-TRADITIONAL-YEAR-STEM-JIE-3D-V01`을 명시했다.

| 전통 방향 규칙용 입력 | 방향·첫 3개 대운 | 선택한 절입 | 기산 산술 |
| --- | --- | --- | --- |
| MALE | 순행 甲午 → 乙未 → 丙申 | 망종 2026-06-06 00:48 | 6,528 / 4,320 = 68/45 모형년, 표시 1.511111 |
| FEMALE | 역행 壬辰 → 辛卯 → 庚寅 | 입하 2026-05-05 20:49 | 38,351 / 4,320 모형년, 표시 8.877546 |

실제 TEXT는 “후보의 연간은 丙(양)이며, 명시한 전통 방향 규칙용 성별값 남성(MALE)을 적용해 순행을 선택했습니다.”와 선택한 절입·명목 분 간격·유리수 및 근거 참조를 출력한다. 첫 대운에 월주 癸巳 자체를 넣지 않는다. JSON/TEXT 모두 명시한 개수(1~20)의 전체 순서를 제공한다. 이 예의 10번째는 癸卯이며 첫 모형 구간은 `[68/45, 518/45)`이다. 표시 소수는 후속 산술에 사용하지 않는다.

실제 입춘 **2026-02-04 05:02**의 두 출생 후보는 독립적인 명식이다.

| 후보 | 연주·월주 | MALE 방향·첫 3개 | 선택 절입·명목 기산 |
| --- | --- | --- | --- |
| 경계 전 | 乙巳 / 己丑 | 역행 戊子 → 丁亥 → 丙戌 | 소한 2026-01-05 17:23, 42,459/4,320 = 14,153/1,440 모형년 |
| 경계 후 | 丙午 / 庚寅 | 순행 辛卯 → 壬辰 → 癸巳 | 경칩 2026-03-05 22:59, 42,837/4,320 = 14,279/1,440 모형년 |

같은 입춘 분에서 FEMALE은 경계 전 순행 `庚寅→辛卯→壬辰`, 경계 후 역행 `己丑→戊子→丁亥`다. 두 후보가 모두 현재 입춘을 향하며 기산만 `AMBIGUOUS`, `age=null`이다. 진단용 명목0분을 정확한0세로 바꾸지 않는다. 연간·월주·진행방향·절입은 해당 후보 안에서만 연결한다. 독립 세운 시각 조회의 두 연도 결과와 출생 후보를 Cartesian product로 합치지 않는다.

**2026-12-31 12:00 / MALE**은 순행 `辛丑→壬寅→癸卯`까지 계산하지만 다음 소한이 없어 기산은 `NEEDS_DATA`다. **2027 연도 라벨 丁未**는 자료 없이 계산되고, **2027-02-04 12:00**의 시각 판정은 해당 입춘이 없어 `NEEDS_DATA`다. 부족한 자료는 서로 다른 기능의 목록이다.

실제 마지막 절입은 **2026-12-07 11:53 대설**이다. 그 표시 분의 경계 후 순행 후보와 그 뒤의 순행 요청은 다음 소한을 필요로 한다. 같은 분의 경계 전 순행은 현재 대설을 향한 `AMBIGUOUS`로 구분한다. 역행은 확보된 이전 절입으로 계산할 수 있으므로12월 전체를 일괄 미지원으로 표시하지 않는다.

```json
[
  {"year":2027,"term":"XIAOHAN","feature":"DA_YUN_START","side":"FORWARD","reason":"MISSING_ADJACENT_JIE"},
  {"year":2027,"term":"LICHUN","feature":"ANNUAL_LUCK_AT_MINUTE","reason":"MISSING_QUERY_YEAR_LICHUN"}
]
```

세운 조회 **2026-01-01 12:00**은 입춘 전이어서 2025 라벨 **乙巳**다. 실제 입춘의 **05:01 → 2025 乙巳**, **05:02 → 2025 乙巳 / 2026 丙午 조건부**, **05:03 → 2026 丙午**를 실행했다. 조회가 출생보다 이르면 `BEFORE_BIRTH_REPORTED_MINUTE`를 남기며 개인 운세 기간으로 설명하지 않는다. 순수 라벨 모드는 `m1=null`, `provenance=null`, 출생 M1 호출0회다.

1989-01-01의 역행 예는 보조 **1988-12-07 06:34 대설**을 사용한다. 해당 겨울 이벤트는 기존 현대 정책에서 검토한 보조 범위이며 1988년 출생/DST 지원이 아니다.

복사 가능한 Node22 PowerShell 양력·음력·성별값 변경·입춘·연말·세운 단독·선택 M2 명령은 [실행 가이드](../KASI_LOCAL_LUCK_GUIDE.md)에 있다. 실제 CLI 21개 출력은 `.private/m7-a7cdf8a-examples-20261110/`에만 보관했다. 네트워크와 API 키를 차단/제거한 subprocess에서 모두 exit0·stderr 공백이었고 양·음력의 명식·M7 facts·설명 의미가 같았다. JSON의 달력 입력 근거까지 무조건 같은 bytes라고 주장하지 않는다. 별도 Node22 npm --silent wrapper도 네트워크/키 없이 실제 실행해 JSON stdout이 직접 Node 출력과 정확히 같은 bytes임을 확인했다. 빌드 뒤 실행7파일 지문도 같았다. 기록은 `.private/m7-a7cdf8a-npm-demo-20261111.json`이다.

## 정책·코드와 신뢰 범위

- 시작 브랜치 `agent/kasi-local-1950-2026-20261109`, 시작 로컬/원격 `c75b1d357fa8cb07e45589c148995c4c69d833ed`, 미커밋 변경0을 확인했다. 기존419/419와 M2 당시 Lab timeout은 이전 기록이다.
- 순수 정책 커밋 `a7ea52ac9740522c7f6fc2a9438014c3c26c55bc`, 연결/검사/가이드 커밋이자 **실제 최종 코드·테스트 SHA `a7cdf8a2d459198a70abe4cd521ea89901b1888a`**다. 이후 변경은 이 실행 기록과 인계 문서뿐이다.
- 공개 전사 S1 三命通會卷二論大運/論太歲, S2 淵海子平卷一論起大運法을 실제 확인했다. 순역·절/중기·3일 비례·월간지 인접 진행과 별도로, 고전 전사에 있는 나머지/동시각 관례를 인정하고 현대 구현의 분 유리수·동분 보류·6자리 HALF_UP 표시를 소프트웨어 선택으로 구분했다. 스캔·비평 판본·권리는 미확인이다. [10항목 정책 표와 실제 URL](../research/M7_LUCK_POLICY_V01.md).
- 기존 60갑자·년주 resolver·12절입 집합·Gregorian day arithmetic을 재사용한다. 새 간지/시간 알고리즘이나 학파를 복제하지 않았다. M7 milestone과 기존 M4 규칙 제안 ID는 별개다.
- 순수 모듈은 방향/순서, 절입 선택/분 간격/유리수, 연도 라벨/시각 판정을 분리한다. 실제 교운일·현재 몇 번째 대운은 달력 가산 근거가 닫히지 않아 **POLICY_UNRESOLVED**다. 365/365.2425/360일이나 소수나이→일수 환산을 숨기지 않았다. 모형 구간을 실제 달력 나이·날짜로 쓰지 않는다.
- 기존 검증된 후보 로더와 same-process 발급 M1을 사용한다. 이미 검증된 이벤트를 지문/프로필에 묶인 불변 실행 문맥으로 한 번 노출/compile한다. 새 M7 발급 결과는 해당 M1·luck·선택 M2 facts와 연결되며 후보간 refs·다른 요청의 결과 교체·변조를 거절한다. 직렬화된 JSON의 status/hash만으로 외부 인증된 객체라고 신뢰하지 않는다.
- 명리 규칙 출처와 KASI 계산 자료 출처를 분리한다. fact/rule/policy/source 및 후보/기둥 refs가 JSON과 설명에 남는다. KASI를 방향 규칙의 원전으로 쓰거나 TXT/G0 receipt를 위조하지 않는다.
- 기본 명식/설명은 그대로이며 새 `kasi:luck`만 선택형이다. 선택 M2는 같은 출생 M1을 재사용하고 세운 시각 조회는 별도 년 경계 호출이다. 대운 입력만 부족하면 독립 세운을 계속 제공한다. 새 기간 요소를 원국의 다섯 번째 기둥으로 넣거나 기간간 관계·십성·강약/길흉을 추가하지 않았다.
