## 개발 중 발견·교정과 미검증 항목

- 초기 억부 집중 검사는 11/13이었다. 합성 검사 도우미가 발급된 계절 결과를 변경 가능한 객체로 감싸 기존 M5가 거절했다. 같은 이유로 다른 원국 간 참조를 거절하는 검사도 목표 단계까지 도달하지 못했다. 도우미의 계절 객체·후보 배열·후보 객체를 동결한 뒤 같은 기대값으로 13/13을 확인했다. 원인 허용폭·E2 방향 검사까지 포함한 마지막 집중 실행은 14/14였다. 기본 계수와 문턱을 바꾸지 않았다.
- 패키지의 공통 M2/M4/M5 객체를 중복 로드하면 같은 원국의 발급 확인도 실패할 수 있다. 공통 의존성이 기존 core와 같은 모듈 인스턴스를 참조하도록 묶었다. 별도 원국·재구성 JSON의 잘못된 연결은 계속 거절한다.
- 첫 최종 패키징 시 비교 문서에 작성 중인 결과가 있어 깨끗한 소스 증명이 성립하지 않았다. 해당 빌드와 문서 초안을 보존한 뒤 실행 SHA의 깨끗한 트리에서 다시 만들었다. 실행 근거는 두 번째 빌드다.
- 과거 S9 빌드와 E1 빌드 사이에 기존 타입 선언 3개의 바이트 차이를 발견했다. 시작 SHA와 실행 SHA의 소스를 각각 별도 폴더에 꺼내 고정 컴파일러로 재빌드해 두 QA 지문을 재현했다. 기존 `dist` 132개 중 129개는 완전히 동일했다. 나머지는 `limitedSynthesisV1.d.ts`, `resourceSupportV1.d.ts`, `wealthResourcePositionV1.d.ts`에서 근거 참조 속성 6곳과 문자열 유니온 1곳의 선언 순서만 달랐다. 이 부분만 정렬하자 그 밖의 모든 바이트가 같았다. 독립 E1 재빌드 `dist` 136/136개는 실제 빌드와 바이트가 일치했다. 세부 이전·이후 지문과 위치는 로컬 `.private/engine-e1-20261122/declaration-compat.json`에 있다.
- 직접 접근할 수 없었던 플러스만세력의 수치식, 다수 상용 원국의 비공개 등급·용신 순위, 독립 전문가 판단, 실제 예측 타당성은 미검증이다. 민감도 시험은 지정한 변형에서만 유효하다.
- 49,799 양음력 쌍 전수는 이번에 다시 실행하지 않았다. 달력 코드·데이터를 변경하지 않았고 주요 경계 및 양음력 동등 입력은 새 API와 독립 패키지에서 별도로 실행했다.
