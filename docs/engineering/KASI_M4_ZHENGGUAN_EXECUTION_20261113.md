## 채택 정책과 문헌 확인 수준

M4-ZHENGGUAN-MONTH-STRUCTURE-V01 / 0.1.0은 기존 M2/1, 구조적 M3/0.1.0과 장간 정책 M2-HIDDEN-STEMS-CLASSIC-MEMBERS-MAINQI-V1의 기존 버전을 소비한다. MAIN_QI 정관은 투출과 별도로 후보, OTHER 정관은 정확 천간 투출 시 후보다. 다른 월령 장간이 연·월·시에 드러나면 경쟁 조건을 보존한다. 일간과만 일치한 장간은 가상의 경쟁 격으로 만들지 않는다.

[정책·결정표](../research/M4_ZHENGGUAN_STRUCTURE_POLICY_V01.md)에 沈 원저, 徐 주석, 전사 차이와 PROJECT_POLICY를 분리했다. NCC의 用神·成敗救應·變化·正官 전사는 직접 확인했고, 동리 원서버 timeout/502 뒤 검색 캐시를 대조했다. 두 표면의 일치는 독립 학파 합의가 아니다. 스캔·비평 판본·권리·전문가·예측 타당성 검증은 하지 않았다. NLC PDF의 metadata 접근을 스캔 판독 성공으로 쓰지 않았다.

NCC의 유효하지 않은 戊甲 명식 문자열은 격리했다. 宣 예의 水局/木局 차이와 金 예의 원저 正官/徐 印格 논의는 자동 교정·효력 정답에 사용하지 않았다. 문헌의 雜氣를 M2 OTHER와 동일시하지 않는다. 午 OTHER 己만 해당 호환 정책 미정이며 기존 장간 구성원을 바꾸거나 모든 후보를 보류하지 않았다. M4의 월령 格局用神 기준은 M5의 도움이 되는 희용신과 다른 결과 타입이다.

재→관, 관→인→일간, 상관→관, 관살 병존, 모든 표면 오합, 재인 위치와 기존 지지 쌍·삼합/삼회 구성원을 실제 위치로 연결했다. 존재와 방향은 관측하되 실제 생조 전달·근력·합거·근 손상·자동 성격/파격/구응은 평가하지 않았다. 기존 규칙의 null 버전 7개를 새 모듈 버전으로 채우지 않았다.

## 실패·수정·재실행의 분리

1. 문헌 예의 MAIN/OTHER 최초 오독은 resolver 작성 전 독립 장간 대조에서 바로잡았다. 원문 雜氣와 OTHER를 혼동하지 않는다.
