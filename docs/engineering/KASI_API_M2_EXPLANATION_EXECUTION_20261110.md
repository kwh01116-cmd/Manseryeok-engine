## 실제 구현과 신뢰 범위

- 기존 `local-chart.mjs`의 성공 결과를 비공개 WeakMap에 내용·요청 지문으로 연결한다. 원래 JSON 필드는 바꾸지 않았다. 이번 실행의 원래 객체가 아니거나, 명식·정책·자료 출처를 바꾸거나, 다른 요청의 결과를 재사용하면 M2 입력으로 거절한다. 이 검사는 실행 연속성이며 외부 출처 인증이나 G0가 아니다.
- `local-chart-facts.mjs`가 이미 계산한 모든 후보를 기존 `deriveM2ChartFactsV3`에 전달하고, 기존 음양/오행 상수와 `twelveGrowthStage`를 추가 연결한다. 새 연주·월주·일주·시주 또는 M2 규칙 표를 복제하지 않았다. 음력은 기존 API 관측 인덱스를 유지하며 완전 음력연도/TXT provenance 타입으로 강제하지 않았다.
- facts 생성 시 후보·기둥·장간·규칙·정책·출처 참조를 검사한 뒤 전체 그래프를 동결한다. 같은 실행이 발급한 불변 객체만 설명기에 전달한다. 복제·재직렬화된 임의 JSON은 신뢰된 실행 객체로 재개할 수 없다. 정적 정책/규칙/출처만 불변 캐시로 공유한다.
- `local-explain.mjs`의 `createLocalExplanationProfile`은 입력당 기존 M1 경로를 한 번 호출한다. `explainChartFacts`는 facts만 소비하는 순수 함수이며 달력 계산을 실행하지 않는다. `validateExplanation`은 후보별 fact/rule/policy/source/template 참조와 실제 문장을 대조한다. `renderExplanationText`도 원래 계산과 설명의 연결을 확인한다.
- JSON에는 원래 M1, 후보별 facts, 규칙/출처 목록, 설명과 factRefs가 있다. 템플릿은 `ko-chart-basic-templates-v1` /1.0.0이다. 생성 시각·확률·LLM 호출·자동 저장은 없다. 출력은 stdout, 새 CLI의 안전한 오류는 stderr JSON이다. 기존 `kasi:chart` 호환성을 유지한다.

## 관측한 실패와 수정

초기 공개 테스트 두 건은 동결된 기존 M1 중첩 객체에 대입해 의도한 검증 전 TypeError가 났다. 최상위 chart를 복제해 교체한 후 변조 검사와, 불변 facts 자체가 변경을 거절하는 검사를 구분했다. 검사 기대값을 일괄 교체하거나 skip하지 않았다.
